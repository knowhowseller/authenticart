## 1. 개인정보보호법

### 리스크 등급: 🔴 즉시 조치

### 1-1. AI 처리 시 고객 데이터 수집·저장·활용 기준

**위반 가능 상황**

서우는 클라이언트 기업의 내부 업무 데이터(매출, 고객 DB, 직원 정보 등)를 AI 에이전트에 입력·분석하는 방식으로 서비스를 제공한다. 이 과정에서 다음 위반 상황이 발생할 수 있다.

- 클라이언트가 서우에게 자사 고객의 개인정보(이름, 연락처, 구매 이력 등)가 포함된 데이터를 제공할 경우, 서우는 개인정보보호법상 수탁자로서 의무를 지게 된다. 위탁계약 없이 처리 시 법 제26조 위반.
- AI 모델(Claude API 등 외부 SaaS) 호출 시 개인정보가 포함된 프롬프트가 제3자 서버에 전송될 경우, 개인정보의 제3자 제공 또는 국외 이전 규정(법 제17조, 제28조의8) 위반 가능성.
- MVP 구축 후 모델 B(구독·리테이너) 전환 시 클라이언트 데이터를 장기간 보유하게 되어 보유 기간 초과 보관 문제 발생 가능.
- 서우 자체 AI 에이전트 시스템에 여러 클라이언트 데이터가 혼재될 경우 클라이언트 간 정보 침해 발생 가능.

**권고 조치 사항**

| 조치 | 구체적 내용 | 기한 |
|------|-----------|------|
| 개인정보 처리방침 수립 | 서우가 처리하는 개인정보의 유형, 목적, 보유 기간, 제3자 제공(AI API 포함) 현황을 명시한 처리방침 작성 및 홈페이지 공개 | M1 |
| 수탁자 의무 이행 | 클라이언트와 체결하는 서비스 계약서에 개인정보 처리 위탁 조항 반드시 포함(법 제26조). 처리 목적·항목·기간·안전조치 의무 명시 | M1 |
| 국외 이전 동의/계약 | Claude API 등 해외 서버에 개인정보 포함 데이터 전송 시 정보주체 동의 또는 표준 계약 체결(법 제28조의8). 클라이언트에게 해당 사실 고지 | M1 |
| 셀별 데이터 환경 격리 | 클라이언트별 독립 API 키, 별도 DB/네임스페이스 적용. 교차 오염 방지 기술 설계 문서화 | M2 |
| 보유 기간 정책 수립 | 프로젝트 종료 후 데이터 삭제 기한(예: 종료 후 6개월) 명시, 구독 고객은 계약 유지 기간 내 보유 후 해지 시 즉시 삭제 절차 수립 | M2 |
| 개인정보 보호책임자(CPO) 지정 | 법 제31조에 따라 개인정보 보호책임자 1인 지정 및 연락처 공개 | M1 |

### 1-2. 위탁처리 계약 필요 항목

개인정보보호법 제26조에 따라 위탁계약서에는 다음 사항이 반드시 포함되어야 한다.

| 필수 포함 항목 | 내용 예시 |
|-------------|---------|
| 위탁 업무의 목적 및 범위 | "AI 에이전트 구축을 위한 고객 데이터 분석 및 모델 학습" |
| 개인정보의 기술적·관리적 보호 조치 | 암호화, 접근통제, 격리 환경 구축 |
| 재위탁 금지 또는 제한 | 외부 AI API 사용 시 재위탁으로 간주될 수 있으므로 명시적 허용 또는 금지 조항 |
| 개인정보 보유 및 파기 | 계약 종료 후 파기 기한, 파기 방법 |
| 수탁자에 대한 관리·감독 | 위탁자의 정기 점검 권한 |
| 손해배상 등 책임에 관한 사항 | 수탁자 귀책 시 배상 책임 |
| 법 위반 시 계약 해지 조항 | |

> 현재 analyst·financial-reporter 보고서에는 "개인정보 처리 위탁계약서 표준화" 필요성이 언급되어 있으나, 계약서 초안 작성 및 법무사 검토가 아직 완료되지 않은 상태임. M1 내 반드시 선행 처리 필요.

### 1-3. PII 마스킹·격리 의무

**위반 가능 상황**

- AI 프롬프트에 성명·연락처·주민번호·계좌번호 등 PII(개인식별정보)가 원문 그대로 포함되어 외부 AI API에 전송될 경우, 개인정보보호법상 안전조치 의무(법 제29조) 위반.
- 직원 8인이 공용 개발 환경에서 작업 시 타 프로젝트 클라이언트 PII에 비인가 접근 가능성 존재.

**권고 조치 사항**

| 조치 | 내용 |
|------|------|
| PII 마스킹 파이프라인 구축 | AI 모델 호출 전 단계에서 자동 PII 탐지·마스킹(정규표현식 또는 NER 모델) 적용. 실명 대신 토큰화된 식별자 사용 |
| 접근권한 최소화 원칙 적용 | 클라이언트별 데이터에 접근 가능한 팀원을 해당 셀 구성원으로만 제한 (접근 로그 기록) |
| 외부 AI API 호출 전 검토 체크리스트 | 프롬프트 내 PII 포함 여부 확인을 개발 워크플로우에 내장 |
| 개인정보 영향평가 (PIA) | 서비스 출시 전 개인정보 처리 위험도가 높은 경우 자체 영향평가 실시 권장 |

### 2-1. 핵심 메시지의 위반 여부 검토

**점검 대상 메시지:**
- "6주 내 작동하는 MVP, 12주 내 첫 매출"
- "컨설팅이 아닌, 결과로 책임지는 빌더"
- "AI-First 실행 환경으로 1/3 비용·1/3 기간 가능"

**위반 가능 상황**

표시·광고의 공정화에 관한 법률(이하 표시광고법) 제3조는 다음을 금지한다.
- 사실과 다른 내용의 표시·광고 (거짓·과장 광고)
- 소비자를 속이거나 오인시킬 우려가 있는 표시·광고 (기만 광고)

"6주 내 MVP, 12주 내 첫 매출"이라는 표현은 조건 없이 단정적으로 사용될 경우 **성과 보증 표현**으로 해석되어 표시광고법 위반 가능성이 있다. 특히 다음 상황에서 위반 가능성이 높아진다.

- 클라이언트 역량·협조 수준에 따라 납기가 달라짐에도 예외 없이 보장처럼 표기하는 경우
- 실제 케이스 중 6주를 초과한 사례가 존재함에도 해당 수치를 일반 원칙으로 광고하는 경우
- "1/3 비용·1/3 기간"의 비교 기준이 명시되지 않아 근거 없는 비교 광고로 간주될 경우

| 🚫 금지 | "1/3 비용으로 동일한 결과" | 비교 기준 미제시 — 근거 없는 비교 광고 |
| 🚫 금지 | "AI 도입으로 업무 효율 3배 상승" | 구체적 수치 보증, 개별 편차 무시 |

| 🟢 허용 | "평균 6주 내 작동하는 MVP 구축 (클라이언트 협업 수준에 따라 상이)" | 평균 기준 + 변수 조건 명시 |
| 🟢 허용 | "12주 이내 첫 매출 달성을 목표로 함께 만들어갑니다" | 목표·노력 표현, 보증 아님 |
| 🟢 허용 | "기존 외주 개발 대비 30~50% 기간 단축 사례 보유 (케이스스터디 링크)" | 실증 사례 기반, 링크 제공 |
| 🟢 허용 | "AI 도입 후 반복 업무 70% 자동화한 클라이언트 사례 (A사, 2026년 2월)" | 특정 사례 인용, 일반화 없음 |
| 🟢 허용 | "결과로 평가받는 빌더 구조 — RevShare·지분으로 성과를 함께 책임집니다" | 구조 설명, 결과 보증 아님 |

### 3-1. 구독(모델 B) 환불 정책 의무 사항

**위반 가능 상황**

전자상거래 등에서의 소비자보호에 관한 법률(전자상거래법)은 주로 소비자(B2C) 거래에 적용된다. 모델 B의 주요 고객이 B2B(사업자)인 경우 전자상거래법 직접 적용은 제한적이나, 다음 상황에서는 적용 가능성 또는 준용이 발생한다.

- 개인사업자·프리랜서·1인 기업과의 계약: 사실상 소비자에 준하는 처우 필요
- 표준약관 미제시 시 약관의 규제에 관한 법률(약관법) 위반 가능성 (불공정 약관 조항으로 분쟁 발생)
- 구독 자동 갱신(Auto-renew) 구조 채택 시 갱신 사전 고지 의무 미이행으로 계약 분쟁 및 평판 리스크

**권고 조치 사항**

| 조치 | 내용 | 기한 |
|------|------|------|
| 구독 서비스 표준 약관 제정 | 서비스 범위, 구독료, 자동 갱신 조건, 환불 정책, 해지 방법을 명시한 표준 이용약관 작성 및 법무사 검토 | M1 |
| 환불 정책 명문화 | 구독 개시 후 환불 가능 기간(예: 서비스 개시 7일 내 미사용 시 전액 환불), 월 중도 해지 시 일할 계산 여부 명시 | M1 |
| 자동 갱신 사전 고지 의무 | 갱신일 30일 전 이메일 등 서면 고지 절차 수립. 고지 미이행 시 갱신 불인정 조항 적용 리스크 인지 | M1 |
| 서비스 수준 협약(SLA) 명시 | 서비스 가용률, 응답 시간, 월별 업데이트 건수 등 수치화된 SLA를 계약서에 명시하여 분쟁 예방 | M1 |

### 3-2. 계약 해지 조건 고지 의무

**위반 가능 상황**

- 구독 최소 계약 기간(Lite 3개월, Standard 6개월, Premium 12개월) 중도 해지 시 위약금 조항이 약관법상 불공정 조항으로 판단될 수 있음. 위약금 비율이 과도할 경우 효력 부인 가능.

### 5-1. 자본시장법 적용 여부 (미등록 투자 권유 리스크)

**위반 가능 상황**

자본시장과 금융투자업에 관한 법률(자본시장법)은 "금융투자업"을 등록하지 않은 자가 투자 권유 또는 금융투자상품 거래를 중개하는 행위를 금지한다.

서우의 모델 C가 다음 구조로 운영될 경우 자본시장법 적용 가능성이 있다.

| 시나리오 | 자본시장법 리스크 |
|---------|---------------|
| 서우가 지분 투자를 받는 대신 서비스를 제공하는 구조 | 지분 수취를 "투자 유치"로 해석 시 — 일반적으로 영업 대가로서 지분 취득은 자본시장법 적용 대상 아님. 단, 모집 방식에 따라 달라짐 |
| 서우가 파트너에게 제3자 투자자를 연결(소개)하고 수수료를 받는 경우 | 투자 중개로 간주되어 미등록 투자중개업 위반 가능성 — 법 제117조 위반 |
| 불특정 다수에게 RevShare 지분 계약을 "투자 상품"처럼 공개 모집하는 경우 | 증권 모집에 해당하여 자본시장법 제9조·제119조(증권신고서 제출 의무) 위반 가능성 |
| Phantom Equity를 "수익 증권" 형태로 구성하는 경우 | 파생결합증권 또는 수익증권으로 해석될 경우 자본시장법상 금융투자상품에 해당할 수 있음 |

**핵심 판단 기준**

- 서우 자신이 서비스 대가로 지분·RevShare를 취득하는 것은 원칙적으로 자본시장법 적용 대상이 아님.
- 그러나 파트너에게 투자자를 연결하거나, 지분 구조를 외부 투자자에게 판매하거나, 불특정 다수를 대상으로 모집하는 순간부터 규제 적용 가능성이 급증함.
- Phantom Equity의 경우 "계약상 권리"로 설계하면 자본시장법 적용을 회피할 수 있으나, 실질적 투자 성격을 띠면 규제 대상이 될 수 있어 법무사·금융법 전문가 필수 검토.

**권고 조치 사항**

| 조치 | 내용 | 기한 |
|------|------|------|
| 자본시장법 전문 법무사·법무법인 자문 | 모델 C 구조 전반에 대해 자본시장법 해당 여부 유권 해석 요청. 특히 Phantom Equity 구조 사전 설계 자문 | M1 최우선 |
| 지분 취득 목적 명확화 | 계약서에 "본 지분 취득은 서비스 제공 대가이며 투자 중개 목적이 아님"을 명시하여 자본시장법 해석 리스크 최소화 | M1 |
| 불특정 다수 모집 금지 | 모델 C 파트너 모집 시 개인적 신뢰 관계 기반 1:1 접촉으로 한정. 공개 플랫폼·광고를 통한 불특정 다수 모집 금지 | 즉시 |

### 5-2. Phantom Equity 노무·세무 리스크

**위반 가능 상황**

Phantom Equity(가상지분)는 실제 지분을 부여하지 않고, 향후 기업 매각·투자 유치 시점에 지분 상당액을 현금으로 지급하는 약정이다. 이 구조에서 다음 노무·세무 리스크가 발생한다.

**노무 리스크**

| 리스크 | 내용 |
|-------|------|
| 근로소득 vs 기타소득 분류 문제 | Phantom Equity 수령자가 서우의 임직원이거나 사실상 근로자로 인정되는 경우, 지급액이 근로소득으로 분류되어 원천징수 의무 발생. 미이행 시 가산세. |
| 사업소득 분류 | 독립 계약자(프리랜서·개인사업자)인 파트너가 수령하는 경우 사업소득으로 분류. 3.3% 원천징수 필요. |
| 근로계약 오분류 리스크 | RevShare를 받는 파트너를 사실상 근로자로 보는 경우, 4대 보험 미가입 및 퇴직금 미지급 문제 발생. |
| 스톡옵션 유사 구조 시 세법 특례 미적용 | 벤처기업법상 스톡옵션 세제 혜택은 요건을 충족한 경우에만 적용. Phantom Equity는 해당 특례 적용 불가. |

**세무 리스크**

| 리스크 | 내용 |
|-------|------|
| 지급 시점 과세 vs 발생 시점 과세 | Phantom Equity는 실현(현금 지급) 시점에 과세되는 것이 원칙이나, 계약 구조에 따라 권리 확정 시점 과세로 해석될 수 있음. |
| 서우의 손금 처리 | Phantom Equity 지급액이 비용으로 처리될 수 있는지, 시점은 언제인지 법인세법상 확인 필요. |
| RevShare 수취 시 부가가치세 | 서우가 RevShare로 수취하는 금액에 부가가치세가 부과되는지 여부 (용역 제공 대가 성격이면 과세 대상). |
| 지분 취득 시 취득세 등 | 기존 법인 신주를 저가로 취득하는 경우 증여세·취득세 문제 발생 가능. |

**권고 조치 사항**

| 조치 | 내용 | 기한 |
|------|------|------|
| 노무사 자문 (계약 유형 확정) | Phantom Equity 수령자를 근로자로 볼 것인지, 독립 계약자로 볼 것인지 사전 확정. 계약서 구조를 이에 맞게 설계 | M1 최우선 |
| 세무사 자문 (소득 구분·원천징수) | 지급 시점·소득 구분에 따른 원천징수 의무 사전 확정. RevShare 부가가치세 처리 기준 수립 | M1 |
| Phantom Equity 계약서 정밀 설계 | 권리 발생 요건, 지급 트리거(엑시트 정의), 지급 금액 산정 방식, 세금 처리 방법(Gross-up 조항 포함 여부) 명시 | M2 |
| 지분 취득 구조별 세무 검토 | 공동법인 설립형·신주 발행형·Phantom Equity형 각각의 세무·법무 효과 비교 후 최적 구조 선택 | M2 |
| RevShare 정산 기준 명문화 | 계약서에 매출 정의(순매출/총매출), 정산 주기(분기), 검증 방법(감사 권한), 미지급 시 위약금 기준 명시 | M1 |

## 6. 추가 주의 사항 — 기타 규제 리스크

### 6-1. 저작권 및 AI 생성물 IP 귀속

**리스크 등급: 🟡 주의**

- AI 도구(Claude, Cursor, v0 등)로 생성된 코드·콘텐츠·디자인의 저작권 귀속이 계약서에 명시되어 있지 않을 경우, 클라이언트와 분쟁 발생 가능.
- 클라이언트가 제공한 데이터를 학습에 활용할 경우, 데이터 저작권 및 영업비밀 침해 가능성.
- 부트캠프(트랙 ④) 수료생의 커리큘럼 자료, 강의 콘텐츠에 대한 저작권 귀속 명확화 필요.

**권고 조치:** 계약서에 "AI 도구 활용 결과물의 저작권은 클라이언트에 귀속되며, 서우는 포트폴리오 활용 목적으로 비상업적 사용 가능"과 같이 명시. AI 학습 데이터 활용 범위를 계약서에 명확히 제한.

### 6-2. 정부 지원사업 (AI 바우처) 관련 준수 의무

**리스크 등급: 🟢 이상 없음 (등록 완료 후 해소)**

- AI 바우처 공급기업 등록 후에는 정해진 서비스 범위 내에서 바우처를 사용해야 하며, 미등록 서비스에 대한 바우처 처리 시 환수 및 공급기업 자격 취소 가능.

**권고 조치:** 바우처 공급기업 등록 시 서비스 범위를 Starter·Standard 패키지에 맞게 정확히 기재. 등록 범위 외 서비스 수행 금지 내부 정책 수립.

### 6-3. 근로계약 및 4대 보험

**리스크 등급: 🟡 주의**

- 부트캠프 수료생을 "협력 빌더"로 활용 시, 실질적 업무 지휘·감독 관계가 발생하면 근로자로 판단될 수 있어 4대 보험 미가입 및 최저임금 위반 문제 발생.
- 도메인 전문가 PO를 개인사업자로 처리할 경우, 전속성·지휘감독성 요건에 따라 근로자 인정 가능성 있음.

**권고 조치:** 협력 빌더·PO 계약 유형(도급 vs 용역 vs 고용)을 노무사와 사전 협의 후 계약서 작성. 근로기준법상 근로자 판단 기준 체크리스트 내재화.
