## 대표 즉시 확인 사항 (5줄 요약)

1. **통신판매업 신고가 제일 먼저다.** 계정 개설·판매 시작 전에 완료해야 하며, 소요 비용 2~5만 원·기간 3~5일. 미신고 과태료 최대 5,000만 원 — 0원 예산이지만 이것은 피할 수 없다.

2. **W-8BEN을 플랫폼 가입 직후 제출하라.** Redbubble·Etsy 가입 시 세금 정보를 요구한다. 미제출 시 수익의 30%를 원천징수(비거주자 기본세율)한다. 제출은 무료·온라인, 한미 조세협약으로 감면 가능.

3. **뉴스레터 구독 페이지에 개인정보처리방침 링크를 걸어라.** Mailchimp 무료 플랜을 써도 EU·UK 구독자가 한 명이라도 있으면 GDPR이 적용된다. 직접 작성 가능하고 비용 0원.

4. **Etsy에서 POD 생산파트너를 등록하지 않으면 계정이 위험하다.** Printful 등 POD사를 shop 설정에 Production Partner로 등록하는 것이 의무다. "Handmade" 표기는 절대 금지.

5. **FTC 인플루언서 규정은 운영 첫날부터 적용된다.** 무료 굿즈를 제공하고 리뷰를 받으면 상대방이 반드시 #ad 또는 #gifted를 표기해야 한다. 이를 요청하지 않으면 우리에게도 책임이 있다.

#### S1-1. 통신판매업 신고 ★ [소액]

- **사업자 유형별 절차**:
  - 주식회사 서우 산하로 운영 시: 법인 사업자등록증 이미 존재 → ①국세청 홈택스에서 사업자등록 정정(통신판매업 업태 추가) → ②정부24 또는 관할 구청에서 통신판매업 신고
  - 대표 개인사업자로 운영 시: ①홈택스 개인 사업자등록(업종코드 525101 통신판매업) → ②통신판매업 신고
- **필요 서류**:
  1. 사업자등록증 사본
  2. 구매안전서비스 이용확인증 (에스크로 계약 후 발급 — 아래 참고)
  3. 통신판매업 신고서 (관할 구청 양식 또는 정부24 전자신고)
- **구매안전서비스 (에스크로) 확인 필요**: 통신판매업 신고 시 에스크로 또는 소비자피해보상보험 가입증명이 필요하다. Redbubble·Society6처럼 플랫폼이 직접 결제를 처리하는 경우 "확인 필요" — 일부 지자체에서 플랫폼 정책으로 대체 인정한 사례 있으나 기준이 상이하므로 관할 구청에 직접 문의할 것.

#### S1-2. W-8BEN 제출 ★ [무료]

- **의무 여부**: Redbubble·Etsy 가입 시 세금 정보 입력 단계에서 요구. 미제출 시 30% 원천징수(미국 비거주자 기본세율).
- **개인 사업자**: Form W-8BEN (개인)
- **법인(주식회사 서우)**: Form W-8BEN-E (법인) — 확인 필요: 법인과 개인이 다른 양식이므로 사업자 유형 확정 후 맞는 양식 작성
- **한미 조세협약 혜택**: 한국 거주자/법인은 한미 조세조약에 따라 특정 소득유형(로열티 등)에 대한 원천징수세율 감면 신청 가능. W-8BEN/W-8BEN-E 작성 시 "조세조약 혜택 신청" 항목 체크 필수.
  - Redbubble의 경우 로열티(royalty) 구조로 수익을 지급. 한미 조세협약상 로열티 원천징수세율이 10%로 감면되거나 협약에 따라 추가 감면될 수 있음 — 확인 필요: 세무사 1회 확인 권장.
- **갱신**: W-8BEN은 통상 3년마다 갱신 필요.
- **비용**: 0원 (플랫폼 내 전자 제출)
- **소요 시간**: 10~15분 (가입 단계에서 즉시)
- **체크 항목**:
  - [ ] Redbubble 가입 시 Tax Information 입력 (W-8BEN 선택)
  - [ ] Etsy 가입 시 Tax Settings에서 W-8BEN 제출

#### S2-2. Mailchimp GDPR 설정 — EU·UK 구독자 double opt-in [무료]

- **적용 조건**: EU 또는 UK 거주자가 뉴스레터를 구독하는 경우 GDPR 적용. Redbubble 등을 통해 영미권에 판매하면 UK 구독자는 거의 확실히 존재.
- **플랫폼 책임 구분**:
  - Redbubble·Etsy 경유 판매: 플랫폼이 구매자 데이터의 처리자(controller). 우리는 고객 PII를 직접 보유하지 않음 → GDPR 직접 의무 최소
  - Mailchimp 뉴스레터 구독자: 우리가 데이터 처리자(controller) → GDPR 의무 직접 발생
- **최소 실행 항목 (Mailchimp Free 플랜에서 가능)**:
  - [ ] Mailchimp Audience 설정 > GDPR-Friendly Forms 활성화
  - [ ] Double opt-in(이중 확인) 켜기: 구독 후 확인 이메일 발송 → 링크 클릭 시 최종 등록 (EU/UK 법적 요건인 "명시적 동의" 충족)
  - [ ] 구독 폼에 명확한 동의 문구 추가: "I agree to receive newsletters. [링크] Privacy Policy"
  - [ ] 모든 발송 이메일 하단에 Unsubscribe 링크 포함 (Mailchimp 자동 처리)
  - [ ] 구독 취소 요청·데이터 삭제 요청(DSAR) 발생 시 30일 이내 처리 — 이메일로 직접 대응 (DSAR은 초기에 드물고, Mailchimp "Archive contact" 기능으로 처리 가능)
- **UK ICO 등록 (확인 필요)**: UK 거주자 개인정보를 처리하는 비UK 사업자는 ICO 데이터 보호 수수료 납부 대상일 수 있음. Tier 1 기준 £35/년. 단, 초기 0명~소수 구독자 단계에서의 실질 집행 위험은 낮음. 구독자가 영국인이 생기는 시점에 ICO.org.uk에서 확인 권장.
- **CCPA (캘리포니아)**: 연매출 $25M 미만, 처리 데이터 10만 명 미만인 경우 적용 제외. 현재 단계에서는 의무 없음. 매출 $25M 초과 시 재점검.
- **비용**: Mailchimp 무료 플랜 설정 변경 = 0원
- **소요 시간**: 30분 (설정 변경)

#### S2-3. Etsy Shop 설정 — POD 생산파트너 등록 + 환불 정책 작성 ★ [무료]

#### S2-4. FTC 인플루언서·리뷰 가이드라인 내부 운영 규칙 수립 [무료]

  - 공개 위치: 포스팅 맨 위 또는 사진·영상 내 (해시태그 뭉텅이에 묻히면 안 됨)
  - 허용 표기: #ad, #gifted, #sponsored, #partner (협찬 제공한 경우)
  - 소비자 리뷰를 선별해 좋은 것만 게시하는 행위도 제한 (오해 소지)
- **우리 책임**: 무료 굿즈를 제공한 크리에이터가 #ad를 달지 않을 경우, 제공자인 우리에게도 책임이 발생할 수 있음.
- **실행 규칙**:
  - [ ] 무료 굿즈 발송 시 메시지에 "Please disclose this as #gifted or #ad in your post per FTC guidelines" 한 문장 포함
  - [ ] 협업 조건을 명시한 간이 협업 요청 메시지 템플릿 작성 (5~10줄)
  - [ ] 한국어 SNS 운영 시 국내 표시광고법도 동일 기준 적용 (#광고, #협찬 표기)
- **한국 표시광고법 적용 시점**: 한국어 콘텐츠 운영 또는 역수입 단계 진입 시 적용. 현재 영어권 오가닉 단계에서는 FTC가 우선.
- **비용**: 0원 (내부 규칙·템플릿 작성)
