## 4. 일본어 키워드 분석

### 4-1. 일본 검색 시장 특성 (사전 고지)

일본은 영미권과 검색 생태계 구조가 다르다. 실무상 중요한 차이점:

| 요소 | 영미권 | 일본 |
|------|--------|------|
| 주요 검색엔진 | Google 92%+ | Google 77% + Yahoo! Japan 20% (야후 재팬은 검색 광고·순위 공유) |
| 이커머스 검색 | Google Shopping·Amazon | **라쿠텐 내부 검색** + Amazon Japan + 메루카리(Mercari) |
| SNS 발견 | Instagram·TikTok·Pinterest | Instagram·Twitter(X)·LINEオープンチャット·TikTok |
| 스티커 문화 | iMessage Sticker (소규모) | **LINEスタンプ** — 캐릭터 팬덤 형성 최강 무기 |
| 쇼핑 트리거 | 검색 → 직접 구매 | SNS 발견 → 트위터 RT → 라쿠텐/메루카리 구매 |
| 캐릭터 굿즈 | 니치 마켓 | **메인스트림 문화** (고양이 캐릭터 IP 선호도 매우 높음) |

> **핵심**: 일본 시장에서는 LINE스탬프(스티커)가 캐릭터 IP 팬덤 형성의 진입점. 인스타그램 캐릭터 계정 → LINE스탬프 → 라쿠텐 굿즈 판매가 검증된 경로.

## 6. 플랫폼별 발견 경로 분석 (유료광고 없는 오가닉 중심)

이 사업은 구글 블로그 SEO보다 **플랫폼 내 알고리즘 발견**이 매출에 훨씬 더 직결된다. 채널별 특성과 전략을 분리한다.

### 6-1. Pinterest — POD 커머스 최강 채널

**왜 Pinterest가 특별한가**

- Pinterest 핀(Pin)은 **구글 이미지 검색에서도 노출**된다 → SEO 2중 효과
- 쇼핑 의도가 있는 사용자가 압도적으로 많음 (플랫폼 이용자의 83%가 구매 결정에 Pinterest 활용, Statista 2024 [추정])
- 핀 수명이 길다 — 인스타·틱톡 게시물은 24~72시간 후 도달 급감, Pinterest 핀은 6~12개월 지속 노출
- "cat gifts" "ragdoll cat art" 같은 키워드가 **Google Shopping 대안**으로 작동
- Etsy 상품 → Pinterest 핀 연동 시 외부 트래픽 전환 가장 효율적

**Pinterest SEO 키워드 전략**

| Cat Mom Life | cat mom gift, gifts for cat moms | 공감형 일러스트 + 상품 |

**Pinterest 알고리즘 인자**: 핀 설명문에 키워드 자연 삽입, 보드명·보드 설명 키워드 최적화, Rich Pin(상품 메타데이터 자동 연동) 설정 필수, 주 10~15개 핀 꾸준히 업로드.
