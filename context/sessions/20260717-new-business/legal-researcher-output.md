## ▶ 대표 즉시 확인 사항 (5줄 요약)

1. **"전량 AI 생성" 결정은 현재 상태로는 저작권 등록이 불가합니다.** 미국 저작권청은 인간의 창작적 기여 없는 순수 AI 생성물의 저작권을 인정하지 않으며, 일본 문화청도 동일한 입장입니다. 저작권이 없으면 "라이선싱 수익모델"의 법적 근거 자체가 성립하지 않습니다.

2. **지금 당장 워크플로우를 바꾸면 비용 거의 0으로 해결됩니다.** AI 생성 후 대표가 ① 이미지를 선별하고 ② Photoshop·Procreate 등으로 수정·조합하는 과정을 남기고 ③ 중간 파일·작업 이력을 보관하면 "인간 저작물" 주장 근거를 확보할 수 있습니다. 단, 수정의 양·질이 "창작적 표현"에 해당해야 하며, 기준이 불명확하므로 변호사 확인이 필요합니다.

3. **상표 등록이 현실적 핵심 보호수단입니다.** 저작권을 확보하지 못하더라도 캐릭터명·로고를 미국 USPTO에 상표로 등록하면 제3자의 동일·유사 사용을 막을 수 있고, 상표 기반 라이선싱 계약도 유효합니다. 출원 즉시 ™ 사용 가능, 등록까지 8~12개월·비용 $250~350/1개 분류.

4. **기존 캐릭터(Pusheen 등)와 실질적 유사성 위험을 출시 전 점검해야 합니다.** AI 생성 이미지가 학습 데이터의 기존 캐릭터를 무단 재현할 가능성이 있으며, 이는 저작권 침해 청구로 이어질 수 있습니다. 캐릭터 최종 디자인 확정 후, IP 전문 변호사에게 실질적 유사성 검토를 받으십시오.

5. **일본 AI 표기 의무화 법제화 상태를 반드시 현시점에서 재확인하십시오.** 2025년 8월 시점에는 법제화 논의 중이었으나 그 이후 상황이 변동됐을 수 있습니다. 일본 진입 전 현재 상태 확인이 필수입니다.

### 3-1. 미국 — AI 생성물 저작권 (최우선)

#### 3-1-A. 법적 기준: 인간 저작자 요건 (Human Authorship Requirement)

**근거 조항**: 17 U.S.C. § 102(a) — "Copyright protection subsists ... in original works of authorship fixed in any tangible medium of expression."

**판례 계보**:
- *Burrow-Giles Lithographic Co. v. Sarony* (1884, U.S. Supreme Court): 저작물은 인간의 정신적 창작물이어야 한다.
- *Feist Publications, Inc. v. Rural Telephone Service* (1991, U.S. Supreme Court): "originality" = independent creation + minimal creativity, 모두 인간에서 비롯돼야 함.

**AI 생성물 핵심 결정**:

**① Zarya of the Dawn 결정 (U.S. Copyright Office, 2023년 2월)**
- 개요: Kris Kashtanova가 Midjourney로 생성한 이미지를 포함한 그래픽 노블 등록 후, 저작권청이 재심사.
- 결론:
  - **텍스트(대표가 작성)**: 저작권 인정
  - **이미지의 선택·배열(레이아웃 결정)**: 저작권 인정 가능
  - **Midjourney 생성 개별 이미지**: **저작권 불인정**
- 이유: 프롬프트 입력자는 최종 결과물을 통제하지 못하므로(AI가 예측 불가능하게 생성), 저작자로 볼 수 없다.
- **우리 상황**: 캐릭터 이미지를 AI로만 생성 → 개별 이미지에 저작권 없음.

**② Thaler v. Perlmutter (U.S. District Court, D.D.C., 2023년 8월 18일)**
- 개요: Stephen Thaler가 AI DABUS가 자율 생성한 이미지("A Recent Entrance to Paradise")의 저작권 등록 거부에 대한 소송.
- 판결(Judge Beryl A. Howell): "Human authorship is a bedrock requirement of copyright." AI는 저작자가 될 수 없으며, 인간 개입 없는 AI 생성물은 저작권 보호 대상 아님.
- 항소: D.C. Circuit 항소 진행 중(2024~). **2026년 7월 현시점 최종 판결 여부 확인 필요**.

**③ Copyright Office 등록 가이던스 (2023년 3월, "Copyright Registration Guidance: Works Containing Material Generated by Artificial Intelligence")**
- AI 생성 요소가 포함된 작품 등록 신청 시:
  - AI 생성 부분은 반드시 **고지(disclaim)**해야 함
  - 인간이 창작한 부분만 보호 청구 가능
  - 허위 고지 시 등록 무효 + 민·형사 책임
- 프롬프트 입력만으로는 저작자성 불충분하다고 명시.

**④ Copyright Office — "Copyright and Artificial Intelligence" Part 2 Report (2025년 1월 추정)**
- 미국 저작권청이 발표한 AI 저작권 종합 보고서 시리즈의 2부. 저작권 가능성(copyrightability) 기준을 다룸.
- 내용 요약(조사자 지식 범위 내): 순수 AI 생성물은 저작권 불인정 입장 재확인. 인간의 "충분한 창작적 통제(sufficient creative control)"가 있어야 저작권 인정 가능. 프롬프트 단독으로는 여전히 불충분.
- **이 보고서의 구체적 기준과 2025년 1월 이후 추가 발표 사항은 현시점 재확인 필요.**

#### 3-1-B. 핵심 질문 1: 순수 AI 생성 캐릭터는 저작권 등록이 가능한가?

**결론: 불가능합니다.**

프롬프트 입력 → AI 생성 → 선택 후 사용하는 순수 AI 워크플로우로는 미국 저작권청에 등록 불가합니다. 등록 거부는 확립된 저작권청 정책이며, 법원 판결로도 지지됩니다.

**저작권 부재 시 결과:**

| 결과 | 설명 |
|------|------|
| 라이선싱 권리 미성립 | 저작권이 없으면 저작권 기반 라이선싱 계약의 법적 근거 없음. 계약은 체결 가능하나 법적 집행력이 약함. |
| 제3자 모방 대응 불가 | 저작권 침해 소송 제기 불가. 누군가 캐릭터를 그대로 복제해도 법적 제지 수단 없음(상표권 범위 외의 경우). |
| DMCA 테이크다운 취약 | DMCA §512 테이크다운은 저작권 침해 청구 기반. 저작권이 없으면 플랫폼에 삭제 요청할 근거가 약해짐. 단, 플랫폼 자체 콘텐츠 정책에 기반한 신고는 가능. |
| 브랜드 가치 제한 | 장기적으로 캐릭터 IP 매각·투자유치 시 저작권 부재가 가치평가 디스카운트 요인. |

#### 3-1-C. 핵심 질문 2: 인간의 창작적 기여를 어느 정도 더해야 저작권이 인정되는가?

**저작권청과 법원의 입장(2025년 8월 기준):**

저작권청은 "인간이 AI를 창작의 도구로 사용하되, 최종 표현의 창작적 측면에 인간이 기여"해야 한다고 봅니다. 그러나 정확한 정량 기준(몇 % 수정, 몇 픽셀 변경 등)은 존재하지 않습니다.

**인정 가능성이 높은 기여:**

| 기여 형태 | 인정 가능성 | 비고 |
|----------|----------|------|
| Photoshop 등으로 실질적 수정 (선 추가, 색상 교체, 요소 재배치) | 높음 | 수정 정도가 "창작적 표현"에 해당해야 함 |
| AI 초안에 대표가 직접 선·표현·디테일 추가 (Procreate 등) | 높음 | 인간 기여분에 대해서만 저작권 주장 |
| 여러 AI 생성 이미지를 창작적으로 선별·배열·콜라주 | 중간 | "선택과 배열"의 창작성 입증 필요 |
| 독창적인 텍스트(캐릭터 이름, 대사, 이야기) 추가 | 높음 | 텍스트 부분은 독립적으로 저작권 |
| AI 생성물의 단순 선택(마음에 드는 것 고르기) | 낮음 | 창작적 기여로 인정되기 어려움 |
| 프롬프트 작성만 | 매우 낮음 | 저작권청이 명시적으로 불충분하다고 확인 |

**왜 프롬프트 작성만으로는 부족한가:**
저작권법상 보호는 "표현(expression)"에 부여되는 것이며 "아이디어(idea)"에는 부여되지 않습니다(아이디어-표현 이분법). 프롬프트는 아이디어의 명세에 해당하며, 최종 표현 결과물을 프롬프트 작성자가 통제·예측했다고 보기 어렵습니다. AI가 같은 프롬프트로도 매번 다른 결과를 생성한다는 점이 이를 뒷받침합니다.

#### 3-1-D. 실무 대응책: 저작권 확보 워크플로우 설계

**권장 워크플로우 (비용 추가 거의 없음):**

```
① AI로 초안 생성 (다수 후보)
   → 중간 파일 전부 보관 (날짜·프롬프트 기록)
② 대표가 선별 (이유와 기준 메모)
   → 단순 선택이 아닌 "왜 이 요소를 선택했는지" 기록
③ Procreate / Photoshop 등으로 수정
   → 수정 전·후 파일 모두 보관
   → 가능하면 수정 과정 타임랩스/스크린 레코딩 보관
④ 수정 결과물이 캐릭터의 "최종 표현"이 됨
   → 이 단계의 결과물에 대해 저작권 청구
⑤ 미국 저작권청 등록 신청 시:
   → AI 생성 부분 고지(disclaim)
   → 인간 수정 부분만 저작권 청구
   → 수정 설명서 첨부
```

**보관해야 할 서류·파일:**
- AI 생성 원본 이미지 파일 (날짜, 사용 도구, 프롬프트 포함)
- 수정 전·후 레이어 파일 (.psd, .procreate 등)
- 작업 일지 (언제, 어떤 수정을 했는지)
- 프롬프트 기록지

**등록 신청 시 AI 사용 고지(Disclaim) 절차:**
- 저작권 등록 신청서(Form CO 또는 온라인)에 "Some AI-generated content" 표시
- AI가 생성한 부분을 "Author's Contribution" 란에서 제외
- 인간이 창작한 부분(수정, 선별, 추가 요소)만 청구 범위 기재
- 필요 시 에세이/설명서 첨부

#### 3-1-E. 저작권 외 대체 보호수단

**① 미국 상표 등록 (USPTO)**

캐릭터 IP 사업에서 저작권이 약하면 상표가 핵심 보호 수단이 됩니다.

| 항목 | 내용 |
|------|------|

| 비용 | TEAS Plus: $250/분류(class), TEAS Standard: $350/분류 |
| 기간 | 출원~등록: 8~12개월 (이의 없는 경우) |
| 효과 | 출원 즉시 ™ 사용, 등록 후 ® 사용, 타인의 유사 사용 금지 청구 가능 |
| 주요 분류 | Class 9 (디지털 스티커·이모티콘), Class 16 (문구), Class 25 (의류), Class 41 (엔터테인먼트 서비스) |
| 라이선싱 | 상표를 기반으로 라이선싱 계약 체결 가능 (저작권 없어도 유효) |
| 출원 방법 | 직접(USPTO.gov) 또는 미국 상표 전문 변호사 통해 진행 |

**② 트레이드 드레스 (Trade Dress)**
- 캐릭터의 독특하고 일관된 시각 외관이 "출처 식별력"을 획득하면 트레이드 드레스로 보호 가능
- 비등록 트레이드 드레스도 사실상 구별력(secondary meaning) 획득 시 보호되나, 입증 부담이 큼
- 브랜드 일관성·장기 사용이 핵심 요건

**③ 계약 기반 보호**
- 라이선시(licensee)와의 계약에서 "이 이미지 세트를 독점적으로 사용할 권리"를 부여하는 방식
- 저작권이 아닌 계약 의무로 구속 → 계약 위반 소송은 가능하나 제3자 복제에는 대응 불가

**④ 미국 특허 (Design Patent)**
- 장식적 디자인에 대한 디자인 특허 가능
- 캐릭터의 특정 외관 보호 가능
- 비용: $1,500~3,000 (변호사 포함), 기간: 1~3년, 유효기간: 15년
- AI 생성물도 인간 발명자(디자이너)가 있으면 출원 가능 (주의: AI 단독 발명 불가 — *Thaler v. Vidal*, 2022)
- 비용 대비 효과는 브랜드 성장 후 검토

### 3-2. 일본 — AI 생성물 저작권

#### 3-2-A. 법적 기준

**근거**: 日本 著作権法 第2条第1項第1号 — "著作物" とは、思想又は感情を創作的に表現したものであつて、文芸、学術、美術又は音楽の範囲に属するものをいう。

→ "창작적 표현"이 요건이며, AI가 자율적으로 생성한 것은 "사람의 사상·감정의 창작적 표현"에 해당하지 않아 저작권 보호 제외.

**일본 입장의 특징:**
- 미국과 마찬가지로 순수 AI 생성물은 저작권 보호 불가
- 그러나 "AI를 도구로 사용(道具として使用)"한 경우는 미국보다 유연하게 해석하는 경향 존재
- 인간이 AI를 붓·카메라처럼 사용해 창작 의도를 실현한 경우 → 저작권 인정 가능

#### 3-2-B. 文化庁 가이드라인 (2024년 3월)

**「AIと著作権に関する考え方について」 (2024년 3월 15일 발표)**

주요 내용:

**창작적 기여(創作的寄与) 인정 범위:**
- "AI가 생성한 것을 그대로 이용하는 경우" → 저작권 보호 제외
- "인간이 AI 출력물을 창작적으로 선택·수정·배열한 경우" → 인간 부분에 저작권 인정 가능
- 특히: 생성 이미지에 대해 인간이 ① 구체적인 묘사 방식을 지시, ② 반복 생성으로 의도 실현을 시도, ③ 수정·편집을 가한 경우 → 인간의 창작적 기여로 볼 가능성 있음

### 3-3. 캐릭터 IP 사업 일반 법적 쟁점

#### 3-3-A. AI 유사성 침해 리스크 (기존 캐릭터와 실질적 유사성)

**리스크 메커니즘:**
AI 이미지 생성 모델(Midjourney, Stable Diffusion 등)은 인터넷상 이미지를 학습 데이터로 사용합니다. 이 데이터에는 Pusheen, Hello Kitty 등 기존 캐릭터 이미지가 포함돼 있으며, 생성 결과물이 기존 저작물과 "실질적으로 유사(substantially similar)"하면 저작권 침해 청구 대상이 될 수 있습니다.

**관련 소송(참고 사례, 2025년 8월 기준 진행 중):**
- *Andersen v. Stability AI* (N.D. Cal., 2023년 1월 제기): 아티스트들이 Stable Diffusion에 대한 집단소송. 학습 데이터 사용 + 출력물 유사성 청구.
- *Getty Images v. Stability AI* (D. Del., 2023년 2월): 사진 저작권 침해 청구.
- 이 소송들은 2024~2025년 계속 진행 중이었으며, **2026년 7월 판결·화해 현황 확인 필요.**
- 중요: 이 소송들은 AI 플랫폼을 대상으로 하지만, 결과에 따라 AI 생성 이미지 사용자(굿즈 판매자 등)에게도 간접 영향 가능.

**랙돌 캐릭터 특유 위험:**
- Pusheen: 회색 태비 고양이, 둥글고 포동포동한 체형, 단순화된 선, 나른한 표정 → 랙돌과 체형·분위기 유사점 있음
- "고양이 캐릭터"라는 속(genus) 자체는 저작권 보호 대상 아님
- 보호되는 것은 Pusheen 특유의 **구체적 표현 요소들의 조합**
- 리스크: AI가 Pusheen 스타일을 학습해 유사한 외관을 생성할 가능성

**사전 회피 방법:**
1. 캐릭터 디자인 확정 후 IP 전문 변호사에게 "유사성 검토(clearance search)" 의뢰
2. 랙돌 특유 외관(무늬, 체형, 눈 색, 자세) + 브랜드 감성(번아웃·나른함 코드)의 독자적 조합 설계
3. 생성 시 기존 캐릭터명을 프롬프트에 사용하지 않음
4. 여러 AI 도구 결과물 교차 검토 → 기존 캐릭터 연상 요소 사람이 제거
5. 독특한 보조 요소(캐릭터의 상징 아이템, 배경 등) 인간이 추가 디자인

#### 3-3-B. 저작권 없는 상태에서 라이선싱 계약 구조

저작권이 없어도 라이선싱 계약은 체결 가능합니다. 단, 법적 근거와 집행력이 다릅니다.

**가능한 대안적 계약 구조:**

| 계약 유형 | 기반 | 집행력 | 제3자 대응 |
|---------|------|-------|---------|
| 상표 라이선싱 계약 | 등록 상표권 | 강함 | 가능 (상표 침해 청구) |
| 이미지 사용권 계약 | 계약 의무 | 중간 (계약 위반) | 불가 (제3자에 대한 권리 없음) |
| 독점 사용 계약 | 계약 의무 | 중간 | 불가 |
| 영업 비밀 기반 | 비공개 의무 | 낮음 (공개 캐릭터에는 적용 어려움) | 불가 |

**권장 구조**: "상표 라이선싱 + 이미지 사용 계약" 병행. 저작권을 취득한 경우 3층 보호(저작권+상표+계약)로 전환.

| Etsy (Etsy Payments 사용) | Etsy가 "마켓플레이스 퍼실리테이터"로 대부분 주의 판매세를 자동 징수·납부. 판매자 별도 처리 최소화. |
| Redbubble | 동일 — Redbubble이 판매세 처리 |
| 자체 웹사이트 (Shopify 등) | 각 주 경제 넥서스 기준 모니터링 필요. Shopify Tax 기능 활용 가능. |
| POD 제품 직접 배송 | Printful 등 POD 업체가 자사 창고 소재 주에서 판매세 징수 처리 가능 |

**실무 시사점:**
- Etsy·Redbubble 등 주요 POD 플랫폼 사용 시 판매세는 대부분 플랫폼이 처리
- 자체 사이트 구축 시 전문가 확인 필요
- 미국 내 법인 설립·직원 고용·재고 보유 없으면 소득세(연방·주) 의무는 제한적이나, 복잡한 세금 이슈는 미국 세무사 확인 필요

#### 3-4-C. 일본 특정상거래법 표기 의무

**「特定商取引に関する法律」(特商法):**
- 통신판매(通信販売) 사업자에게 표기 의무 부과
- 해외 사업자도 일본 소비자에게 판매 시 적용 (이론상)

**표기 필수 항목:**
| 항목 | 내용 |
|------|------|
| 販売業者名 | 판매자(사업자)명 |
| 住所 | 주소 (한국 주소 기재 가능, 단 명확하게) |
| 電話番号 | 전화번호 |
| 販売価格 | 판매 가격 (소비세 포함 여부 명시) |
| 送料 | 배송료 |
| 支払方法 | 결제 방법 |
| 商品引渡時期 | 배송 기간 |
| 返品・交換・キャンセル | 반품·환불 정책 |
| 不良品 | 불량품 처리 |

**해외 사업자 특이사항:**
- 일본 내 주소 없을 시 한국 주소 표기 가능하나, 일본어로 명기 필요
- 라쿠텐 입점 시: 라쿠텐이 특상법 표기를 입점 심사에서 확인하므로 한국 정보 + 일본어 번역 필요
- 2023~2024년 논의: 개인 사업자의 주소 비공개 특례(대리 주소 허용) 법안 논의 중이었음 — **2026년 7월 현행 규정 확인 필요**

**일본 소비세(消費税):**
- 일본 소비자에게 디지털 콘텐츠(이모티콘, 디지털 다운로드 등) 판매 시, 과세 매출 ¥10,000만 이상이 되면 일본 소비세 등록·납부 의무 발생 가능
- 굿즈(POD) 판매는 물리적 수출로 처리되어 소비세 면세 가능 (플랫폼 매커니즘에 따라 다름)
- **세무사 확인 필요**
