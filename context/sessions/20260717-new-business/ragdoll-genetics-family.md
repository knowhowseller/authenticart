# 랙돌(Ragdoll) 색상·패턴 유전학 & 10마리 가족 트리 설계

> 목적: 10마리 캐릭터 앙상블의 **가족 트리(부모→자식 교배 조합)를 유전적으로 타당하게** 설계.
> "이 부모 조합에서 이 색/패턴 자식이 나올 수 있는가"를 판정하는 근거 문서.
> 표기 규칙: **[확인]** = 유전 법칙/문헌으로 확정, **[추정]** = 브레더 실무 통설이나 개체차·논쟁 여지 있음.

---

## 0. 한 줄 요약

- 랙돌의 색·패턴은 사실상 **5개의 독립 스위치**로 결정된다: ① 검정계열 B/b(씰↔초콜릿), ② 묽음 D/d(진한색↔묽은색), ③ 오렌지 O(X염색체 연관, 레드/토티), ④ 화이트 스포팅 S(컬러포인트↔미티드↔바이컬러↔반), ⑤ 아구티 A(태비=링스).
- **열성은 부모 양쪽이 있어야 나온다**(초콜릿·묽음·화이트없음). **우성은 부모 중 최소 1마리에 있어야 나온다**(화이트 스포팅·링스·오렌지).
- **핵심 결론(사용자 희망 검증):** `곰탱(초콜릿) × 희망(라일락) → 똘망(씰 토티 아들)`은 **유전적으로 3중 불가**. 아래 §6에서 이유와 대안 트리 2안을 제시한다.

## 1. 포인트 컬러 유전 (진한색 ↔ 묽은색)

### 1-1. 검정 계열 B 로커스 (씰·초콜릿·시나몬) [확인]
우성 순서: **B > b > b1**
- **B** = 검정계열(랙돌에선 포인트가 **씰=진갈색/검정**으로 발현)
- **b** = 초콜릿 (열성)
- **b1** = 시나몬 (b에도 열성 = 가장 열성). *랙돌 표준에는 시나몬/폰이 사실상 없음 → 본 설계에서 제외.* [확인]

규칙:
- **B_ (BB 또는 Bb) → 씰**. 겉모습이 씰이어도 Bb면 초콜릿 유전자를 "숨겨서" 보유(캐리어).
- **bb → 초콜릿**. 초콜릿은 열성이므로 **두 부모 모두 b를 물려줘야** 나온다. [확인]

### 1-2. 묽음 D 로커스 (Dilute) [확인]
- **D** = 진한색(dense, 우성), **d** = 묽음(dilute, 열성)
- **dd(두 개 모두 d)일 때만** 색이 묽어진다:
  - 씰(B_ dd) → **블루**
  - 초콜릿(bb dd) → **라일락**
  - 레드(O dd) → **크림**
- dd는 열성 → **묽은색(블루·라일락·크림)은 부모 양쪽이 d를 물려줘야** 나온다. [확인]

### 1-3. 두 스위치를 겹친 4색 매트릭스 [확인]

| | 진한(D_) | 묽은(dd) |
|---|---|---|
| **씰계열(B_)** | 씰 Seal | 블루 Blue |
| **초콜릿계열(bb)** | 초콜릿 Chocolate | 라일락 Lilac |

### 1-4. 교배 결과 — 실측 확률 (양쪽 부모가 Bb Dd 캐리어일 때) [확인]
문헌 표(BluQueen 등)와 멘델 법칙 일치:
- **씰 × 씰**(둘 다 Bb Dd) → 씰 56.25% / 블루 18.75% / 초콜릿 18.75% / 라일락 6.25%
- **블루 × 블루**(둘 다 dd, Bb) → 블루 75% / 라일락 25% (묽음은 유지, 초콜릿계열만 갈림)
- **초콜릿 × 초콜릿**(둘 다 bb) → 초콜릿 75% / 라일락 25% — **씰은 0%**
- **라일락 × 라일락**(둘 다 bb dd) → 라일락 100%
- **컬러포인트 × 컬러포인트** → 컬러포인트 100% (§3)

### 1-5. ★ "초콜릿 × 초콜릿에서 씰이 나올 수 있는가?" → **불가** [확인]
- 초콜릿 개체 = **bb**. b밖에 가진 게 없어 **자식에게 b만 물려준다.**
- 자식은 반드시 **bb**(초콜릿) 또는 bb dd(라일락). **B가 어디서도 들어올 수 없으므로 씰(B_)은 절대 불가.**
- 일반화: **열성색 두 마리에서 더 진한색(우성)은 못 나온다.** 라일락×라일락 → 씰/블루/초콜릿 전부 불가. 블루×블루 → 씰/초콜릿(진한색) 불가(둘 다 dd라 진한색 D를 못 준다).
- 역방향은 가능: **씰(Bb Dd) × 씰(Bb Dd) → 라일락 자식 가능**(숨은 b·d가 만나 bb dd). 진한색 부모가 묽은/초콜릿 캐리어면 더 묽고 열성인 자식이 나온다.

## 2. 레드/토티 유전 (성염색체 X 연관)

### 2-1. 오렌지 O는 X염색체에 있다 [확인]
- 표기: **X^O**(오렌지) / **X^o**(비오렌지). 최근 원인 유전자는 X염색체상 **ARHGAP36** 결실로 밝혀짐. [확인]
- **오렌지는 검정계열 색을 덮는다(상위성/epistasis).** 레드 고양이는 밑에 씰인지 초콜릿인지 상관없이 겉은 레드. **즉 레드 개체도 B/b·D/d를 숨겨 보유**하고 자식에게 물려줄 수 있다. [확인]
  - 레드가 dd면 → **크림**(레드의 묽은색).

### 2-2. 성별에 따른 발현 [확인]
- **수컷(XY)**: X 한 개 → X^O면 레드, X^o면 비레드. **토티 불가**(한 X뿐이라 두 색을 못 섞음).
- **암컷(XX)**: X 두 개 →
  - X^O X^O = 레드(크림), X^o X^o = 비레드(씰/블루/초콜릿/라일락),
  - **X^O X^o = 토티(tortie)** — 세포마다 어느 X가 꺼지는지 랜덤(라이언화)이라 레드+비레드가 얼룩짐. [확인]
- 따라서 **토티는 거의 100% 암컷.** [확인]

### 2-3. 토티가 나오려면 부모에게 필요한 것 [확인]
자식이 토티(X^O X^o 암컷)가 되려면 **한쪽 X는 오렌지, 다른 쪽 X는 비오렌지**여야 한다:
- **딸에게 아빠는 항상 자기 X를 준다.** 그러므로
  - **아빠가 레드(X^O Y)** → **모든 딸은 아빠의 X^O를 받음** → 엄마가 비오렌지면 **딸은 전원 토티**, 엄마가 오렌지면 딸은 레드. (아빠 레드는 "딸=반드시 오렌지" 제약을 만든다 — 설계 시 중요)
  - **아빠가 비레드(X^o Y)**면, 토티 딸은 **엄마가 오렌지를 줘야** 나온다 → **엄마가 레드 또는 토티**여야 함.
- 요약: **토티 자식 = (오렌지 X 1개) + (비오렌지 X 1개)**. 부모 중 **최소 한쪽이 오렌지(레드 또는 토티)를 반드시 공급**해야 한다. 부모 둘 다 비레드면 토티·레드 자식은 **불가**. [확인]

### 2-4. 수컷 토티가 극히 드문 이유 [확인]
- 정상 수컷은 X가 하나뿐 → 두 색을 못 가짐.
- **XXY(클라인펠터형, 약 1/3,000)**일 때만 수컷이 X 두 개를 가져 토티 가능. 대개 **불임**. [확인]
- → 스토리에서 **"수컷 토티"를 만들면 사실상 불임·초희귀 개체 설정**이 강제된다. 권장하지 않음.

## 3. 패턴 유전 (컬러포인트·미티드·바이컬러·반)

랙돌의 흰색은 **화이트 스포팅(White Spotting Factor, WSF)** 유전자가 조절. 흰색 없음 → 미티드 → 바이컬러 → 반(고백색)으로 흰색량이 커진다. **화이트 스포팅은 우성**이라 부모 중 최소 1마리에 있어야 한다.

### 3-1. 확정된 뼈대 [확인]
- **컬러포인트 = 흰색 전혀 없음 = ss(화이트 스포팅 없음, 열성).**
- **컬러포인트 × 컬러포인트 → 자식 100% 컬러포인트.** (ss × ss = 전부 ss) [확인]
  → **두 컬러포인트에서 미티드·바이컬러·반은 절대 안 나온다.** 흰색은 반드시 흰색 있는 부모에서 온다.
- 미티드(발·턱·배의 흰색)·바이컬러(역V 마스크+더 넓은 흰색)는 **화이트 스포팅 대립유전자를 최소 1개** 가진 상태. [확인]

### 3-2. 실무 모델 — 두 갈래가 통용됨 [추정]
문헌마다 표기가 갈리나(단일유전자 불완전우성 vs. s2·s4 두 대립유전자), **실무 결론은 대체로 일치**:
- **미티드는 우성 형질**(부모 중 1마리에서 옴), 컬러포인트에 대해 우성. [확인]
- **미티드 × 미티드 → 컬러포인트·미티드·바이컬러(=하이미티드)까지 모두 출현 가능.** (미티드 대립유전자 2개가 겹치면 흰색이 커져 바이컬러처럼 보임) [확인/실무]
- **트루 바이컬러(이형접합) × 컬러포인트 → 약 50% 바이컬러 / 50% 컬러포인트.** [추정/실무]
- **호모(하이미티드) 부모 × 컬러포인트 → 자식 전원 미티드**(전원이 스포팅 1개 상속). [추정/실무]
- **바이컬러 × 바이컬러 → 컬러포인트~미티드~바이컬러~고백색(반)까지 넓게 분포**(흰색량 극대 개체=반). [추정/실무]

### 3-3. 조합에서 나오는 자식 패턴 (설계용 요약)
| 부모 A × 부모 B | 나올 수 있는 자식 패턴 | 근거 |
|---|---|---|
| 컬러포인트 × 컬러포인트 | 컬러포인트만 | ss×ss [확인] |
| 컬러포인트 × 미티드 | 컬러포인트 / 미티드 (**바이컬러·반 불가**) | 흰색 공급이 미티드 대립 1개뿐 [추정] |
| 미티드 × 미티드 | 컬러포인트 / 미티드 / 바이컬러(하이미티드) | [확인/실무] |
| 바이컬러 × 컬러포인트 | 바이컬러 / 컬러포인트 | [추정] |
| 바이컬러 × 바이컬러 | 컬러포인트~미티드~바이컬러~반(고백색) | [추정] |

> **반(Van)** = 화이트 스포팅 최대 등급(색이 귀·꼬리·마스크에만 남음). 랙돌에선 등록단체별로 정식 인정이 갈리며 보통 **바이컬러/하이화이트 라인의 극단**으로 본다. **반은 고백색 라인(바이컬러×바이컬러 등)에서 나오는 개체**로 설정. [추정]

## 4. 링스(태비/아구티) 유전 [확인]

- **링스 = 아구티(태비) 유전자 A가 포인트 위에 얹힌 것**(줄무늬 포인트). **A는 우성.**
- 랙돌의 모든 색은 컬러포인트(cs/cs) 기반이라, 포인트 부위에만 태비 줄무늬가 드러남.
- **우성이므로 자식이 링스면 부모 중 최소 1마리가 링스여야 한다.** [확인]
- **비링스 × 비링스 → 링스 자식 불가**(우성은 무에서 안 생김). [확인]
- 링스는 **어느 색·패턴에도 얹힐 수 있다**(씰 링스, 블루 링스 바이컬러, 라일락 링스 미티드 등).
- **토티 + 링스 = 톨비(torbie)**: 토티 암컷이 아구티를 가지면 얼룩+줄무늬. [확인]

## 5. 설계용 유전 규칙 요약 (판정 체크리스트)

자식 후보가 나올 수 있는지 볼 때 이 5개만 확인하면 된다:

1. **씰/초콜릿(B/b)**: 초콜릿·라일락 자식 → **부모 둘 다 b 보유** 필수. 초콜릿계열 부모 두 마리에서 씰 자식 **불가**.
2. **묽음(D/d)**: 블루·라일락·크림 자식 → **부모 둘 다 d 보유** 필수. 묽은색 부모 두 마리에서 진한색 자식 **불가**.
3. **오렌지(O)**: 레드·토티 자식 → **부모 중 최소 1마리가 오렌지(레드/토티) 공급** 필수. 토티=암컷. 아빠가 레드면 **딸 전원 오렌지(레드/토티)**.
4. **화이트(S)**: 미티드·바이컬러·반 자식 → **부모 중 최소 1마리가 흰색 보유** 필수. 컬러포인트 두 마리 → 자식 전원 컬러포인트.
5. **링스(A)**: 링스 자식 → **부모 중 최소 1마리가 링스** 필수.

> 열성(초콜릿·묽음·화이트없음)은 "양쪽에 있어야", 우성(오렌지·화이트·링스)은 "한쪽에만 있어도" — 이 대칭만 기억하면 대부분 판정됨.

## 6. ★ 사용자 희망 검증: `곰탱 × 희망 → 똘망(아들)`

**곰탱 = 초콜릿 컬러포인트, 희망 = 라일락 미티드, 똘망 = 씰 토티(아들 희망)**

### 판정: **유전적으로 불가 (3중 위반)** [확인]

1. **씰 불가(B 위반):** 곰탱(초콜릿)=bb, 희망(라일락)=bb dd. **둘 다 bb라 b만 물려줌 → 자식은 전원 초콜릿계열(초콜릿/라일락). 씰(B_)은 절대 불가.** (§1-5)
2. **토티 불가(O 위반):** 곰탱·희망 **둘 다 비오렌지**. 오렌지 공급원이 없으므로 **레드·토티 자식 자체가 불가.** (§2-3)
3. **아들 토티 불가(성 위반):** 토티는 X 두 개가 필요 → **거의 암컷 전용.** "아들 토티"는 XXY 불임 초희귀 개체여야만 성립. (§2-4)

### 대안 A (권장) — **새 부모 2마리 + 8마리 = 한 남매 앙상블**
사용자 힌트("추가 2마리로 부모 세대를 채운다")를 그대로 살린 안. **새 2마리를 부모, 명명된 8마리를 모두 자식(남매)** 으로 두면 8마리 전원이 유전적으로 성립한다.

- **아빠(신규 #9) "노을" — 씰 링스 바이컬러 ♂**  · 유전자: **Bb Dd**, **아구티(링스) 보유**, **바이컬러(화이트)**, 비오렌지(X^o Y)
  → 링스·화이트를 공급하고, b·d를 숨겨 보유해 초콜릿·묽은색 자식을 가능케 함.
- **엄마(신규 #10) "달래" — 씰 토티 바이컬러 ♀**  · 유전자: **Bb Dd**, **오렌지 보유(X^O X^o = 토티)**, **바이컬러(화이트)**
  → 오렌지를 공급(레드·토티 자식 가능). **아빠가 비오렌지라서 "딸 전원 오렌지" 제약이 없음** → 비오렌지 딸도, 레드 아들도 자유롭게 나옴.

이 한 쌍에서 8마리가 전부 성립하는 근거:

| 자식(명명) | 색/패턴 | 성 | 유전 근거(왜 가능한가) |
|---|---|---|---|
| 아리 | 씰 바이컬러 | ♂/♀ | B_ (둘 다 B 보유) · 바이컬러(양쪽 화이트) · 비오렌지 개체 [확인] |
| 파랭 | 블루 미티드 | ♂/♀ | B_ **dd**(양쪽 Dd→25% dd) · 미티드(화이트 대립 1개) [확인] |
| 곰탱 | 초콜릿 컬러포인트 | ♂ | **bb**(양쪽 b 보유) · 컬러포인트=ss(양쪽이 화이트 이형접합이면 ss 자식 가능) [확인] |
| 발랑 | 씰 링스 | ♂ | 링스=아빠에게서 아구티 상속(우성) · B_ [확인] |
| 쭈리 | 레드 바이컬러 | ♂ | 아들이 엄마 X^O 받으면 레드 · 바이컬러 [확인] |
| 소망 | 반(고백색) | ♂/♀ | 바이컬러×바이컬러 → 흰색 극대 개체=반 [추정] |
| 희망 | 라일락 미티드 | ♂/♀ | **bb dd**(양쪽 b·d 보유) · 미티드 [확인] |
| 똘망 | 씰 토티 | **♀** | 엄마 X^O + 아빠 X^o = 토티 · B_ = 씰 토티 [확인] |

> 주의: 이 8마리를 "한 배 새끼"로 보기보다 **같은 부모에게서 여러 배에 걸쳐 태어난 형제자매**로 설정하는 게 현실적(랙돌 한 배는 보통 3~5마리). 스토리상 "10남매 대가족" 또는 "8남매 + 부모"로 자연스럽다.
> 단 하나의 강제 제약: **똘망은 반드시 암컷**(토티). 나머지는 성별 자유(위 표는 예시).

### 대안 B — 사용자의 "부부" 감성을 살린 2쌍 구조
곰탱·희망을 **부부로는 유지**하되, 그 자식은 초콜릿/라일락 계열만 가능(씰·토티·레드·바이컬러 불가)함을 반영. 똘망은 레드 아빠 라인으로 분가.

- **쌍1: 쭈리(레드 바이컬러 ♂) × 아리(씰 바이컬러 ♀, Bb Dd)**
  → **똘망(씰 토티 ♀)** = 딸(아빠 X^O + 엄마 X^o, 아빠가 레드라 **딸은 전원 토티**) · **소망(반)** = 바이컬러×바이컬러 고백색 · 그 외 씰/블루 바이컬러·미티드 남매. [확인]
- **쌍2: 곰탱(초콜릿 컬러포인트 ♂) × 희망(라일락 미티드 ♀)**
  → 자식은 **{초콜릿 또는 라일락} × {컬러포인트 또는 미티드}** 만. 예: 라일락 미티드, 초콜릿 컬러포인트 새끼.
  **씰·블루·레드·토티·바이컬러·반은 전부 불가**(bb 부부 + 화이트 공급 1개뿐). → 여기에 **신규 새끼 1마리(예: "몽이" 라일락 미티드)** 배치. [확인]
- **발랑(씰 링스)·파랭(블루 미티드)**: 링스는 우성이라 부모가 필요 → 발랑을 **쌍1의 링스 보유 자식**으로 두려면 아리/쭈리 중 하나가 링스여야 함. 아니면 **발랑을 별도 부모(신규 파트너와 쌍3)로**. → 유연성이 대안 A보다 낮음.

**결론: 대안 A를 1순위로 권장**(전원 성립 + "새 2마리=부모" 힌트 충족 + 제약 최소). 곰탱·희망을 꼭 부부로 하고 싶으면 대안 B, 단 두 사람의 자식은 초콜릿/라일락 계열로 한정됨을 스토리에 반영.

**설정 바이블 고정값(변경 금지):**
- **똘망은 반드시 암컷**(토티=X 두 개 필요, 수컷 토티는 불임 초희귀). [확인]
- **초콜릿/라일락(곰탱·희망)은 부모 둘 다 b 보유가 전제** → 노을·달래를 Bb로 고정. [확인]
- **블루/라일락(파랭·희망)은 부모 둘 다 d 보유 전제** → 노을·달래를 Dd로 고정. [확인]
- **레드/토티(쭈리·똘망)의 오렌지는 엄마 달래(토티)에서 공급** → 달래를 토티로 고정. [확인]
- **링스(발랑)의 아구티는 아빠 노을에서 공급** → 노을을 링스로 고정. [확인]
- **화이트(미티드·바이컬러·반)는 노을·달래 둘 다 바이컬러라 공급 충분.** 단 **컬러포인트 자식(곰탱)은 두 부모가 화이트 이형접합일 때만** 나옴. [추정]

**빠른 판정 예시(스토리 작가용):**
- "곰탱(초콜릿)과 아리(씰)는 형제인가?" → 가능. 부모 노을·달래가 Bb라 한 배에서 씰·초콜릿 둘 다 나옴. [확인]
- "발랑(링스)의 링스는 누구에게서?" → 아빠 노을(링스). 엄마 달래는 비링스라 링스는 부계. [확인]
- "쭈리(레드)와 똘망(토티)이 남매인 이유?" → 둘 다 엄마 달래의 오렌지(X^O)를 물려받음. 쭈리=아들이라 레드, 똘망=딸이라 토티. [확인]
