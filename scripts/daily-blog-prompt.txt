오센틱아트(공예 원데이클래스 예약 + 핸드메이드 작품 마켓) 블로그 자동 발행 작업이다. `keyword-blog` 스킬의 규칙을 따른다.

## 입력
`out/today-keywords.json` — 오늘 발행할 키워드 목록. 각 항목 {keyword, target, intent, vol, score}.

## 작업
각 키워드마다 블로그 원고 1편을 작성해, 전체를 `outputs/04-marketing/posts-auto-{{DATE}}.json` 파일로 저장하라. **발행(publish-blog.mjs 실행)은 하지 말고 JSON 파일만 생성**한다.

## 파일 형식
{
  "posts": [ { slug, title, excerpt, content, category, tags:[], faq:[{q,a}×4], is_featured:false, seo_title, seo_description, keyword, intent } ],
  "unfeature": []
}

## 각 post 필드
- slug: 한글-하이픈. **기존 발행분과 중복 금지** — `D:\키워드엔진\publish_log.csv`의 오센틱아트 행 URL들과 겹치지 않게 유니크하게.
- title, excerpt(2~3문장)
- content: 마크다운 900~1300자, H2 소제목 3~4개, 마지막에 CTA 링크 1개
- category: guide|story|trend|instructor 중 타겟에 맞게 (입문·학부모=guide, 커플=story, 선물=trend, 강사=instructor)
- tags: 3~5개, faq: 정확히 4개 [{q,a}]
- seo_title, seo_description
- keyword: 입력 키워드 그대로, intent: 입력 의도 그대로
- is_featured: 전부 false (홈 featured는 별도 관리)

## 작성 규칙 (고정, 위반 금지)
- **의도 일치**: intent가 상업·거래면 순수 how-to 금지 → **후기/추천형 서술 + 예약·작품 CTA**. 정보면 가이드/경험형.
- **헤드 롱테일 우회**: 광의·완제품쇼핑 키워드(은반지·디퓨저·서울데이트 등)는 **지역+공예유형 롱테일 각도**로("공방에서 만드는 은반지", "서울 공방 데이트 코스" 등). 완제품 구매 의도로 쓰지 말 것.
- **광고법 안전**: "최고/유일/1위/보장/완벽/무조건" 및 허위 후기 표현 금지. 체험을 권유하는 담백한 톤.
- **브랜드 톤**: 따뜻·현실적, 이모지 절제.
- **CTA 실제 라우트만**: /classes(클래스 예약) · /artworks(작품) · /group-request(단체) · /signup/instructor(강사). 마크다운 링크로.
- 강사 정산 언급 시 **86.7%**(PG 3.3%+플랫폼 10% 공제) 고정.

## 마무리
파일 저장 후 "생성완료 N편: 제목1 / 제목2 / ..." 한 줄만 보고. 다른 파일은 만들지 말 것.
