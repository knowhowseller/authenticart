> 이 문서는 오센틱아트에만 해당하는 실측 상태와 할 일이다.

## 현재 상태 (2026-07-12 실측)

| 항목 | 값 |
|---|---|
| 발행(자사웹) | 37건 |
| **색인률** | **41%** (7일 경과분 기준 63%) → 60% 미만 구간 = **발행 제동** |
| 색인 실패 | 발견-미크롤 13건 · 구글모름 7건 · **크롤 후 색인거부 2건** |

**원인 진단**: 기술 문제가 아니라 **하루 3편 × 1,000자 얇은 글**의 대량 발행이 원인. 크롤 예산을 태워 색인률이 떨어졌다.

## 이미 적용된 것 (코드에 심어둠)

- `scripts/publish-quota.mjs` — 엔진의 색인률을 읽어 **오늘 발행 편수를 결정**(80%↑ 2편 / 60%↑ 1편 / **미달 0편 + 보강모드**). `run-daily-blog.ps1`이 이걸 먼저 호출하고, 0편이면 신규 발행을 건너뛴다.
- `scripts/check-content.mjs` — 발행 전 색인 게이트: 본문 2,000자 · 고유 수치 3개 · 내부링크 2개 · 추출형식(표/번호) · FAQ 4개. 하나라도 미달이면 Claude 재작성으로 넘어간다.
- `scripts/daily-blog-prompt.txt` — BLUF(질문형 H2 아래 완결된 답 1문장), 고유 수치, 내부링크 규칙 명시. **1,000~1,400자 상한 폐기 → 2,000자 이상**.

## 지금 해야 할 일 (우선순위)

1. **미색인 글 보강이 신규 발행보다 우선.** 색인률 60% 회복 전까지 자동 발행은 0편으로 멈춘다(정상 동작).
   - **크롤 후 색인거부 2건** — 품질 탈락. 본문을 2,000자 이상으로 대폭 보강하거나 유사 글과 병합:
     - `/blog/상견례-결혼기념일-핸드메이드-선물`
     - `/blog/집들이-선물-추천-직접-만드는-핸드메이드-한점`
   - **발견-미크롤 13건** — 내부링크를 걸어 중요도 신호를 준다(기존 글 → 이 글).
2. 보강 후 GSC에서 **재크롤 요청**(URL 검사 → 색인 요청).
3. 색인률 회복(60%+)되면 쿼터가 자동으로 1편/일로 풀린다. 80% 넘으면 2편.
