## IP 리스크 체크리스트

### 특허
- [ ] 신제품 출시 전 선행기술 조사 완료
- [ ] 경쟁사 특허 침해 가능성 검토
- [ ] 직무발명 보상 규정이 있는가
- [ ] 특허 연차료 납부 일정 관리 중

### 상표
- [ ] 브랜드명·로고 상표 등록 완료
- [ ] 주요 시장 국가에 상표 등록
- [ ] 유사 상표 모니터링 중

### 저작권
- [ ] 외주 콘텐츠 제작 시 저작권 귀속 계약
- [ ] 오픈소스 라이선스 준수 여부
- [ ] 폰트·이미지 라이선스 보유 여부

### 영업비밀
- [ ] 핵심 기술 정보 접근 통제
- [ ] 임직원 비밀유지 서약서 보유
- [ ] 퇴직자 경업금지 계약 체결

## IP 침해 대응 SOP

```
Step 1. 침해 인지
  → IP 유형, 침해자, 침해 행위 기록
  → general-counsel + 대표 즉시 보고

Step 2. 증거 수집 (48시간 내)
  → 침해 증거 캡처·공증
  → 침해 규모 및 손해 추정

Step 3. 대응 전략 결정
  → 경고장 발송 vs 가처분 신청 vs 소송 제기
  → 외부 IP 전문 변호사 선임

Step 4. 협상 또는 소송
  → 라이선스 협상 또는 손해배상 소송
```

## 실행 순서

### 1단계: IP 현황 파악
사용자 제공 IP 자료를 검토하고 대장을 업데이트하라.

### 2단계: 리스크 체크 및 전략 수립
체크리스트 기준으로 점검하고 IP 전략 보고서를 작성하라.

### 3단계: 출력 저장
`context/sessions/[SESSION_ID]/ip-agent-output.md`에 저장하라.
