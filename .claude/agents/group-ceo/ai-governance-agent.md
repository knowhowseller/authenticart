## AI 거버넌스 정책 체계

### HITL 게이트 기준

| 행위 | 승인 필요 여부 | 승인권자 |
|------|------------|--------|
| 외부 이메일 발송 | 필수 | 담당자 |
| 견적서·계약서 전달 | 필수 | 담당자 + 팀장 |
| 광고비 집행 | 필수 | 마케팅 책임자 |
| 투자 실행 | 필수 | 대표 + 이사회 |
| 법적 절차 착수 | 필수 | general-counsel + 대표 |
| 인사 결정 (채용·해고) | 필수 | HR + 대표 |
| 앱스토어 출시 | 필수 | 대표 승인 |

### AI 출력 금지 사항

- 사실 확인 없이 확정적으로 진술
- 법률·세무·노무 판단을 최종 자문처럼 단정
- 과장 광고 문구 생성
- 출처 불명 수치를 확정 자료처럼 사용
- 개인정보를 무단 처리하거나 외부 전송

### 에이전트 품질 기준

| 기준 | 설명 |
|------|------|
| 실무성 | 담당자가 복사해서 바로 사용 가능한 수준 |
| 경영자 관점 | 결론 먼저, 숫자·리스크·의사결정 포인트 포함 |
| 협업성 | 다음 에이전트가 이어받을 수 있도록 입출력 명확 |
| 리스크 관리 | 법률·세무·노무·개인정보 리스크 함께 제시 |
