### 핵심 7가지 포인트

**포인트 1 — 시스템은 이미 완성되어 있습니다**

오센틱아트는 아이디어 단계가 아닙니다. 강사 스튜디오, 예약·결제, 쇼핑몰, 작품 마켓, B2B 단체 출강, 전국 지부 관리, 관리자 대시보드까지 — 서비스 운영에 필요한 모든 기반 인프라가 완성된 상태입니다.

**포인트 2 — 강사에게 업계 최고 조건을 제공합니다**

클래스 수익의 86.7%가 강사에게 귀속됩니다. 클래스101(약 65%) 대비 연간 780만 원 차이. 이 구조 자체가 강사 유입의 핵심 레버입니다.

**포인트 3 — 국내 어느 경쟁사도 이 조합을 갖추지 못했습니다**

클래스 예약 + 공예 재료 쇼핑 + 수강생 작품 마켓 + B2B 단체 출강 + 전국 지부 네트워크 + 멀티벤더 + 에이전시 시스템까지 — 이 7개 기능을 동시에 갖춘 플랫폼은 현재 국내에 존재하지 않습니다.

**포인트 4 — 공예 전 장르로 플랫폼을 확장합니다**

레진아트로 시작한 플랫폼이 캔들·플라워·도자기·주얼리·자수·회화·목공예까지 아우르는 8개 장르 통합 카테고리 체계로 전환합니다. 각 장르의 강사, 재료 공급사, 에이전시가 하나의 플랫폼 생태계 안에서 만납니다.

**포인트 5 — 재료 공급사가 플랫폼에 직접 입점합니다**

멀티벤더 시스템을 통해 공예 재료 공급사가 직접 상품을 등록하고, 강사가 클래스 준비물로 연결하면 수강생이 원스톱으로 구매합니다. 플랫폼은 수수료 수익을 얻고 공급사는 신규 판매 채널을 확보합니다.

**포인트 6 — 강사 에이전시가 플랫폼에 입점합니다**

공방, 스튜디오, 강사 에이전시가 소속 강사를 묶어 입점할 수 있습니다. 플랫폼이 강사와 에이전시 양쪽에 직접 정산하되, 에이전시별 수수료율을 개별 협의로 설정합니다.

**포인트 7 — 파트너는 초기 투자 없이 합류할 수 있습니다**

모든 파트너십 모델은 매출 발생 시에만 수수료가 부과됩니다. 예약·결제·정산 시스템을 즉시 활용하며 플랫폼 성장과 함께 자산을 형성합니다.

## 1. 사업 배경 및 문제 정의

### 1-1. 시장의 문제: 강사도, 수강생도, 공방도 불편합니다

대한민국 공예·예술 클래스 시장에는 수많은 재능 있는 강사들이 있습니다. 레진아트, 캔들, 플라워, 도자기, 주얼리 — 이들은 자신의 기술로 사람들에게 기쁨을 선물합니다. 그런데 이 생태계에는 구조적인 문제가 세 가지 있습니다.

**문제 1 — 강사의 수익이 너무 많이 깎입니다**

클래스 1건을 팔면 플랫폼이 30~35%를 가져갑니다. PG 수수료까지 더하면 강사 실수령은 60~65% 수준입니다. 월 300만 원 매출 중 100만 원 이상이 플랫폼 몫으로 빠져나갑니다.

**문제 2 — 수강생은 여러 앱을 넘나들어야 합니다**

클래스는 프립에서 예약하고, 재료는 스마트스토어에서 따로 구매하고, 완성된 작품을 팔려면 아이디어스에 등록합니다. 수강생이 배우고 → 만들고 → 팔고 → 가르치는 성장 여정을 한 곳에서 지원하는 플랫폼이 없습니다.

**문제 3 — 작은 공방은 혼자 모든 것을 감당합니다**

지역 공방 운영자는 강사이자 마케터이자 예약 담당자이자 정산 담당자입니다. 예약 시스템 하나 구축하는 데 5,000만 원 이상, PG사 계약은 2~3개월이 걸립니다. 전국 단위로 수강생을 모을 방법도 없습니다.

**문제 4 — 재료 공급사에게 공예 전문 판매 채널이 없습니다**

공예 재료 공급사는 스마트스토어나 자사몰에 의존합니다. 강사가 추천하는 재료, 수강생이 바로 필요한 재료를 정확한 타이밍에 노출하는 전문 채널이 없습니다.

## 2. 시장 기회

### 2-1. 시장 규모: TAM / SAM / SOM

| 구분 | 정의 | 추정 규모 | 산출 근거 |
|------|------|---------|---------|
| **TAM** | 국내 취미·공예·원데이클래스 + 수공예 재료 + 핸드메이드 마켓 전체 | **약 3.5조 원** | 통계청 문화·여가 소비 + 공예재료 유통 업계 추정치 |
| **SAM** | 온라인 플랫폼 중개 가능한 공예 클래스·재료·작품 거래 시장 | **약 6,000억 원** | 아이디어스 연 거래액 1,500억 + 공예 클래스 플랫폼 합산 추정 |
| **SOM** | 오센틱아트의 1년차 현실적 점유 목표 | **약 20~30억 원** | 강사 50명 × 월 평균 GMV 300만 원 × 12개월 |

> 시장 규모 수치는 공개 업계 추정치 기반 참고용이며, ±20~30% 오차 가능성이 있습니다.

---

### 2-2. 지금이 적기인 4가지 이유

**트렌드 1 — MZ세대 '만들기' 경험 소비의 폭발**

완성품 소비에서 "내가 직접 만드는" 경험 소비로 빠르게 전환 중입니다. 원데이클래스 경험 비율은 20~40대 여성 기준 약 70%에 달합니다.

**트렌드 2 — 기업 B2B 팀빌딩·문화행사 수요 급성장**

기업 복지 예산 중 "체험형 문화 활동" 비중이 늘고 있습니다. 공예 팀빌딩은 건당 50~300만 원 규모로, 개인 클래스의 10~50배 단가입니다.

**트렌드 3 — 기존 플랫폼 수수료 불만으로 강사 이탈 조짐**

클래스101의 30~35% 수수료에 대한 불만이 강사 커뮤니티에서 지속적으로 제기됩니다. 오센틱아트의 86.7% 정산율은 이 수요를 직접 흡수하는 강력한 레버입니다.

**트렌드 4 — 공예 전문 통합 플랫폼 공백**

클래스, 재료, 작품 마켓, 에이전시, 벤더를 하나로 묶는 공예 전문 플랫폼은 현재 국내에 존재하지 않습니다. 선점하는 플랫폼이 생태계 표준이 됩니다.

### 3-2. 구축 완료된 9개 핵심 시스템

**[1] 강사 스튜디오 시스템**
강사가 직접 클래스를 등록하고, 회차별 일정 관리, 예약 승인·거절, 월 정산 확인. 클래스 복사·마감·리뷰 답글 기능 포함.

**[2] 수강생 예약·결제·후기 시스템**
즉시 예약(instant)과 강사 승인형(request) 지원. 토스페이먼츠 연동, 대기자 알림, 쿠폰 적용, 자동 이메일.

**[3] 공예 재료 쇼핑몰**
클래스 연계 재료를 같은 플랫폼에서 구매. 단품·장바구니 멀티결제, 배송 관리.

**[4] 수강생 작품 마켓**
수강생이 제작한 작품을 올리고 거래. 클래스 수강 경험이 판매 신뢰도를 높이는 구조.

**[5] B2B 단체 출강 요청 시스템**
기업·기관 단체 출강 요청 → 조건 협의 → 강사 배정. 그룹 레슨·클래스 오픈 요청 기능 포함.

**[6] 전국 지부 네트워크 관리**
지부·지부장 DB, 수수료 분배 구조, 지역별 강사 귀속 관리.

**[7] 강사 승인제 (품질 관리)**
강사 신청 → 관리자 심사 → 승인·반려. 검증된 강사만 등록되는 신뢰 구조.

**[8] 관리자 대시보드**
KPI 차트, 강사·클래스 승인, 예약·주문 관리(검색·필터·강제취소·환불), 정산, 쿠폰, 공지사항.

**[9] 마케팅·참여 도구**
쿠폰, 위시리스트, 대기자 알림, 강사 피처링, 공지사항 시스템.

## 4. 장르 카테고리 체계

### 4-1. 8개 대장르 + 소카테고리

오센틱아트는 레진아트 중심 플랫폼에서 벗어나 공예·예술 전 장르를 아우르는 통합 카테고리 체계를 구축합니다.

| 코드 | 대카테고리 | 소카테고리 예시 |
|------|----------|--------------|
| `resin` | 레진아트 | 레진 코스터·트레이, 레진 주얼리, UV레진 소품, 에폭시 아트 |
| `candle` | 캔들·디퓨저 | 소이캔들, 밀랍캔들, 젤캔들, 룸스프레이, 디퓨저, 왁스 타블렛 |
| `flower` | 플라워·압화 | 프리저브드 플라워, 드라이 플라워, 압화 액자, 생화 꽃다발 |
| `ceramic` | 도자기·석고 | 물레 도자기, 핀칭 도자기, 석고 방향제, 석고 오브제 |
| `jewelry` | 주얼리·비즈 | 와이어 주얼리, 비즈 목걸이·팔찌, 실버 주얼리, 천연석 가공 |
| `textile` | 자수·뜨개·패브릭 | 프랑스 자수, 리본 자수, 코바늘 뜨개, 대바늘, 스트링아트 |
| `painting` | 회화·수채화·아크릴 | 수채화, 아크릴화, 유화, 캘리그라피, 드로잉 |
| `craft` | 목공예·가죽·기타 | 목공예 소품, 가죽 공예, 마크라메, 종이공예 |

### 4-2. 카테고리가 연결하는 것들

동일한 카테고리 코드가 클래스·상품·작품·강사 전문 분야를 관통합니다.

```
[캔들 카테고리 예시]

캔들 강사 등록 → 전문 장르: candle 선택
       |
캔들 클래스 개설 → 카테고리: candle/소이캔들
       |
캔들 재료 벤더 입점 → 상품 카테고리: candle
       |
강사가 클래스 준비물로 벤더 상품 연결
       |
수강생: 클래스 예약 → 준비물 구매(원스톱) → 작품 마켓 등록
```

### 6-1. 수익원 전체 구조

| 수익원 | 과금 방식 | 단가 / 마진 | 성장 시나리오 |
|--------|---------|-----------|------------|
| **클래스 예약 수수료** | 결제액의 10% | 클래스 평균 5만 원 → 건당 5,000원 | 강사 50명 × 월 60건 = 월 1,500만 원 |

| **에이전시 수수료** | 결제액의 에이전시별 설정% | 에이전시율 10% × 건당 5만 원 = 5,000원 | 에이전시 소속 강사 매출 비례 |
| **작품 마켓 수수료** | 거래액의 10% (200건 이후 도입) | 작품 평균 5만 원 × 10% = 5,000원 | 월 200건 → 월 100만 원 |
| **B2B 단체 출강** | 건당 단가 | 1건당 50~300만 원 | 월 5건 → 월 750만~1,500만 원 |
| **향후 수익원** | 구독 키트, 지부 로열티, 광고·프리미엄 노출 | 중기 이후 | 매출 다각화 |

- 전문 강사의 "쓰는 재료" 추천 효과로 일반 쇼핑몰 대비 전환율 우위

### 모델 B | 강사 에이전시 파트너

```
에이전시 입점 승인

강사별 클래스 운영 → 플랫폼이 수익 자동 배분
    |
플랫폼 → 강사 직접 지급 (강사 수령율%)
         → 에이전시 직접 지급 (에이전시율%)
```

**수익 구조:**

| 주체 | 수령 | 비고 |
|------|:---:|------|

| 에이전시 | 협의된 % (예: 5~15%) | 어드민이 에이전시별 개별 설정 |
| 플랫폼 | 10% | 고정 |
| PG | 3.3% | 고정 |

**기대 효과:**
- 에이전시 보유 강사 풀 → 플랫폼 강사 수 빠른 확장
- 에이전시 브랜드 신뢰도를 플랫폼이 흡수
- 플랫폼 직접 정산 → 강사 미지급 분쟁 원천 차단

### 의사결정 요청사항

- [ ] **재료 공급 벤더 파트너십**: 상품 입점 + 강사 연결 + 수수료 15% 조건 → 합류 / 조건 협의 / 보류
- [ ] **강사 에이전시 파트너십**: 소속 강사 공급 + 에이전시율% 개별 협의 → 합류 / 조건 협의 / 보류
- [ ] **클래스 콘텐츠 파트너십**: 브랜드 클래스 채널 + 수수료 86.7% → 합류 / 조건 협의 / 보류
- [ ] **B2B 단체 출강 파트너십**: 기업 네트워크 활용 공예 팀빌딩 공동 전개 → 합류 / 검토 / 보류
- [ ] **지부 파트너십**: 로컬 공간·강사 제공 + 플랫폼 인프라 활용 → 합류 / 조건 협의 / 보류
- [ ] **공동사업자 합류**: 자본·역량 결합, 지분 구조, 역할 분담 → 상세 협의 일정 조율
