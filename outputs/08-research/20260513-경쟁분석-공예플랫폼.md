**작성일:** 2026-05-13 | **분석 기준:** 공개 정보 + 플랫폼 DB 구조 실측치

## 핵심 요약 (경영자용 3줄 요약)

> **오센틱아트의 결정적 우위:** 클래스 + 재료 쇼핑 + 작품 마켓 + B2B 출강을 하나의 플랫폼에서 운영하는 구조는 국내 경쟁사 어디도 갖추지 못한 조합이다. 강사 수수료 86.7% 수령은 업계 최고 수준으로 강사 유치의 가장 강력한 레버다.
> **즉시 해결해야 할 약점:** 브랜드 인지도 0에서 시작하는 트래픽 문제가 유일하며 가장 치명적인 병목이다.
> **6개월 내 생존 조건:** 레진아트 강사 50명 확보 → 후기 200건 → SEO 클러스터 구축의 순서로 속도전이 필요하다.

## 1. 시장 규모 및 성장성

### TAM / SAM / SOM

| 구분 | 시장 범위 | 추정 규모 | 산출 근거 |
|------|---------|---------|---------|
| TAM (전체 가용시장) | 국내 취미·공예·원데이클래스 + 수공예 재료 + 핸드메이드 마켓 | 약 3.5조 원 | 통계청 문화·여가 소비 + 공예재료 유통 추정치 |
| SAM (서비스 가능시장) | 온라인 플랫폼 중개 가능한 공예 클래스·재료·작품 거래 | 약 6,000억 원 | 아이디어스 연 거래액 1,500억+클래스 플랫폼 합산 추정 |
| SOM (현실 점유 목표) | 1년차 레진·캔들·플라워 특화 공예 플랫폼 | 약 20~30억 원 | 강사 50명 × 월 평균 GMV 300만 원 × 12개월 |

> ⚠️ 시장 규모 수치는 공개된 업계 추정치 기반 참고용입니다. 실제 조사 데이터로 검증 필요.

## 3. 경쟁사별 상세 분석

### 아이디어스 (idus.com) — 국내 1위 핸드메이드 마켓

| 항목 | 내용 |
|------|------|
| 핵심 서비스 | 핸드메이드 작가 마켓 (완성품 판매), 소규모 클래스 |
| 수익 모델 | 판매 수수료 20%+PG |
| 강점 | 국내 1위 브랜드 인지도, 앱 생태계 완성, 작가 DB 최대 |
| 약점 | **클래스 기능 빈약**, 재료 판매 없음, 수수료 불만 작가 이탈 |
| 공략 포인트 | 아이디어스 활동 강사에게 "수수료 86.7% + 클래스 + 재료 판매" 3종 패키지 이전 유도 |

### 클래스101 (class101.net) — 온라인 클래스 플랫폼

| 항목 | 내용 |
|------|------|
| 핵심 서비스 | 영상 기반 온라인 강의, 키트 상품 |
| 수익 모델 | 강의 수수료 30~40%, 키트 판매, 구독 수익 |
| 강점 | 대규모 콘텐츠 라이브러리, 브랜드 인지도, 구독 기반 안정 수익 |
| 약점 | **오프라인 공방 경험 제공 불가**, 강사-수강생 직접 소통 어려움, 수수료 높음 |
| 공략 포인트 | "영상으로 배웠다면, 직접 만들어 보세요" — 온라인 시청자를 오프라인 클래스로 전환 유도 |

### 탈잉 (taling.me) — 재능공유 플랫폼

| 항목 | 내용 |
|------|------|
| 핵심 서비스 | 재능공유 플랫폼 (1:1 과외·그룹 레슨·원데이클래스) |
| 수익 모델 | 수업 중개 수수료 약 20% |
| 강점 | 재능 다양성, 1:1 맞춤 매칭 |
| 약점 | **공예 전문성 없음**, 강사 검증 체계 약함, 재료 판매 연계 없음 |
| 공략 포인트 | 탈잉 공예 카테고리 강사들은 전문 공예 플랫폼으로 이동할 유인 높음 |

## 5. 경쟁 우위 분석

### 결정적 강점 6가지

**① 업계 최고 수준의 강사 수익 배분 (86.7%)**
- 클래스101 약 65%, 아이디어스 약 80%, 탈잉 약 80%와 비교 시 압도적
- 월 300만 원 매출 강사 기준 — 클래스101 대비 연간 **780만 원** 추가 수익
- 강사 모집 자료의 핵심 킬러 메시지

**② "클래스 + 재료 + 마켓" 수직 통합 (국내 유일)**
- 수강생 → 재료 구매 → 작품 판매 → 강사 등록의 풀 라이프사이클이 한 플랫폼 완결
- 1~2년 내 경쟁사가 복제하기 어려운 시스템적 해자

**③ B2B 단체 출강 시스템 (블루오션)**
- group_lesson_requests 시스템 이미 구축 완료
- 기업 복지몰·팀빌딩 예산은 건당 50~300만 원 규모 (개인 클래스의 10~50배)

**④ 전국 지부 네트워크 구조**
- 지부·지부장·수수료 분배 DB 구조 완성
- 서울 외 지역 공방 강사를 조직화하는 유일한 기반

**⑤ 강사 승인제 기반 신뢰 시스템**
- 탈잉·프립과 달리 강사 자격 심사 후 승인
- "검증된 강사"라는 수강생 신뢰 확보

**⑥ 수강생 클래스 오픈 요청 시스템 (국내 유일)**
- 수요가 확인된 클래스만 열림 → 강사 리스크 최소화, 수강생 원하는 클래스 보장

### 즉시 해결해야 할 약점

| 약점 | 심각도 | 해소 방법 |
|------|-------|---------|
| 브랜드 인지도 제로 | 매우 높음 | SEO 콘텐츠 + 강사 기반 바이럴 |
| 모바일 앱 미구현 | 높음 | PWA 단기 대응 → 앱 중기 개발 |
| 트래픽 없음 | 매우 높음 | 강사별 SEO 페이지 + 블로그 콘텐츠 |
| 초기 네트워크 효과 미작동 | 높음 | 레진아트 특화 집중 공략으로 밀도 확보 |
