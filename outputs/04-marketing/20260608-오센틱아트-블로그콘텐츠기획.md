# 오센틱아트 AI 검색(AEO/GEO) 최적화 블로그 콘텐츠 기획서

> **작성 기준일:** 2026년 6월 8일
> **적용 블로그:** authenticart.kr/blog (기 구현)
> **핵심 목표:** ChatGPT·Perplexity·Google AI Overviews·네이버 큐에 오센틱아트 콘텐츠가 인용·노출되고, 예약/강사신청/단체문의/입점 전환으로 이어지는 콘텐츠 자산 체계 구축

---

## Executive Summary — 3줄 결론

1. **P0 7편을 첫 2주 안에 발행하라.** 강사 수수료 비교·팀빌딩·방과후 강사 콘텐츠는 경쟁 난이도가 낮고 전환 가치가 높아 즉시 AI 인용 및 예약 전환이 가능하다.
2. **4개 타겟 모두 퍼널 입구가 다르다.** 수강생은 장르/지역, 강사는 수익 계산, B2B는 출강 가이드, 벤더는 입점 비교 콘텐츠가 각각 인입점이다. 필러 체계로 분리해야 채널 혼선 없이 전환된다.
3. **원소스 멀티유즈가 핵심 효율이다.** 블로그 1편 → 인스타 카드뉴스 + 유튜브 쇼츠 + 네이버 카페 + 뉴스레터로 재가공하면 월 18편 블로그가 실질적으로 90개 이상의 콘텐츠 접점을 만든다.

## 1. 콘텐츠 필러(Pillar) 체계

> 각 필러는 독립된 타겟/퍼널/키워드 클러스터를 커버한다. 모든 블로그 글은 반드시 하나의 필러에 귀속시킨다.

### 필러 A — 공예 입문 가이드 (수강생 Awareness → Conversion)

| 항목 | 내용 |
|------|------|
| 타겟 | 수강생·취미러 |
| 퍼널 단계 | Awareness → Interest → Conversion |
| 콘텐츠 목적 | 공예를 처음 접하는 사람이 장르·비용·준비물을 파악하고 클래스를 예약하도록 안내 |
| 카테고리 코드 | `guide` / `review` |
| 커버 키워드 클러스터 | 공예 취미 추천, 레진아트 원데이클래스, 공예 원데이클래스 처음, 커플 공예 체험, 혼자 가는 원데이클래스, 공예 클래스 비용, 지역별 공예 클래스 |
| AEO 목표 | "공예 원데이클래스 처음이면 뭐 해요?" 류 질문에 AI가 오센틱아트 콘텐츠를 인용 |
| 주요 CTA | 클래스 예약하기 (`/classes`) |

### 필러 B — 강사 수익화 로드맵 (강사 Interest → Conversion)

| 항목 | 내용 |
|------|------|
| 타겟 | 예비·현직 공예 강사 |
| 퍼널 단계 | Interest → Consideration → Conversion |
| 콘텐츠 목적 | 강사가 수익 구조·플랫폼 비교·개설 절차를 이해하고 오센틱아트 강사 신청으로 전환 |
| 카테고리 코드 | `guide` / `instructor` |
| 커버 키워드 클러스터 | 공예 강사 되는 법, 클래스 플랫폼 수수료 비교, 레진아트 강사 월 수입, 공방 없이 강사, 공예 부업 수익화, 클래스101 대안 |
| AEO 목표 | "공예 강사 수수료 낮은 플랫폼 어디야?" 류 질문에 AI가 오센틱아트 86.7% 수치를 인용 |
| 주요 CTA | 강사 신청하기 (`/signup/instructor`) |

### 필러 C — B2B 출강·팀빌딩 기획 (기관·기업 Awareness → Conversion)

| 항목 | 내용 |
|------|------|
| 타겟 | 기업 HR 담당자, 학교 교사, 복지관 담당자 |
| 퍼널 단계 | Awareness → Interest → Conversion |
| 콘텐츠 목적 | 단체 공예 체험의 기획 방법·비용·효과를 설명하고 단체 출강 문의로 전환 |
| 카테고리 코드 | `guide` / `trend` |
| 커버 키워드 클러스터 | 기업 팀빌딩 공예, 단체 원데이클래스, 방과후 공예 강사 섭외, 자유학기제 공예, 노인복지관 공예 프로그램, 공예 출강 견적 |
| AEO 목표 | "기업 팀빌딩으로 공예 어떻게 신청해요?" 류 질문에 AI가 오센틱아트 B2B 프로세스를 인용 |
| 주요 CTA | 단체 출강 문의 (`/b2b`) |

### 필러 D — 벤더·마켓 입점 가이드 (판매자 Awareness → Conversion)

| 항목 | 내용 |
|------|------|

| 콘텐츠 목적 | 판매 채널 선택 기준을 교육하고 오센틱아트 벤더/작가 입점으로 전환 |
| 카테고리 코드 | `guide` |
| 커버 키워드 클러스터 | 공예 재료 도매, 핸드메이드 작품 판매 채널, 아이디어스 대안, 공방 재료 납품, 공예 작품 마켓 수수료 비교 |
| AEO 목표 | "핸드메이드 작품 팔기 좋은 플랫폼 어디예요?" 류 질문에 오센틱아트 마켓 특징 인용 |
| 주요 CTA | 벤더 입점 신청 / 작품 등록 (`/my/artworks`, 벤더 입점 페이지) |

### 필러 E — 강사 스토리·인터뷰 (브랜딩 + 신뢰)

| 항목 | 내용 |
|------|------|
| 타겟 | 강사(전환 유지) + 수강생(신뢰 형성) |

| 커버 키워드 클러스터 | 레진아트 강사 월 수입 현실, 취미 가르치며 돈 버는 법, 공방 창업 대신, 공예 강사 전업 전환 |

| 주요 CTA | 강사 신청 / 오센틱아트 강사 찾아보기 |

### 필러 F — 공예 트렌드·인사이트 (브랜드 허브화)

| 항목 | 내용 |

요약(40~60자): 클래스101 35%, 탈잉 30%, 프립 20%, 오센틱아트 13.3%(PG 포함)로 강사 실수령이 가장 높습니다.

**본문 아웃라인 (H2/H3 — 자연어 질문형)**
