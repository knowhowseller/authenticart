# 오센틱아트 마케팅 실행 계획
## Phase 1~3 로드맵 기반 채널별 전략 · 예산 · KPI

> **작성 기준일:** 2026년 5월 14일  
> **적용 로드맵:** 비즈니스 보고서 v2 3단계 성장 계획 기반  
> **핵심 목표:** Phase 1 강사 50명 · 후기 200건 · 월 GMV 5,000만 원

---

## Executive Summary

오센틱아트 마케팅의 핵심 레버는 단 하나, **"강사 수수료 86.7%"**입니다.

클래스101(65%) 대비 연간 780만 원을 더 벌 수 있다는 메시지가 강사를 유입시키고, 검증된 강사의 클래스가 수강생을 끌어들이며, 수강생이 재료를 사고 작품을 팔면서 플랫폼 생태계가 돌아갑니다. 공급자(강사) 획득 → 수요자(수강생) 자연 유입 순서로 마케팅을 설계합니다.

**Phase 1 마케팅 3대 축:**
1. **강사 집중 공략** — 레진아트 강사 DM·커뮤니티 (수수료 메시지)
2. **SEO 선점** — "공예클래스 [지역]" 키워드 블로그 100편
3. **B2B 씨앗 심기** — HR 담당자 대상 공예 팀빌딩 패키지 영업

---

## 1. STP 전략

### 1-1. 세분화 (Segmentation)

| 세그먼트 | 설명 | 규모 (추정) |
|---------|------|-----------|
| **레진아트 강사** | 이미 인스타·유튜브로 팔로워 보유. 타 플랫폼 수수료에 불만. | 국내 활동 강사 2,000~5,000명 |
| **취미 공예 수강생** | 20~40대 여성. 원데이클래스 경험 70% 이상. 재구매율 높음. | 핵심 수요층 200만 명+ |
| **기업 복지 담당자** | 팀빌딩·문화행사 예산 보유. 체험형 활동 선호. | 전국 기업 수만 개 |
| **공예 재료 공급사** | 스마트스토어 중심 운영. 강사 추천 채널 없음. | 국내 활동 공급사 수백 개 |

### 1-2. 타겟팅 (Targeting)

**Phase 1 집중 타겟:** 레진아트 강사 (공급자) + 서울·경기 공예 수강생 (수요자)

- 레진아트는 오센틱아트 창업자의 전문 분야 → 신뢰 기반 영업 가능
- 강사 유입이 수강생 유입을 자동 유발하는 구조
- 레진아트 성공 → 캔들·플라워·도자기 순차 확장

### 1-3. 포지셔닝 (Positioning)

> **"강사에게 가장 공정한 공예 플랫폼"**

경쟁사 대비 강사 수수료 86.7%를 전면에 내세워, 수수료에 지친 강사를 집중 흡수합니다.

**부수 포지셔닝:**
- 수강생: "클래스 예약부터 재료 구매까지 한 곳에서"
- 기업: "전문 공예 강사와 함께하는 팀빌딩"
- 공급사: "강사가 추천하는 재료 쇼핑몰 입점"

## 2. Phase별 마케팅 실행 계획

### Phase 1 (0~6개월): 레진아트 거점 구축 + 강사 50명

**핵심 목표:**
- 강사 50명 승인 완료
- 누적 후기 200건
- 월 GMV 5,000만 원
- 구글 "공예클래스 [지역]" 키워드 3페이지 이내 진입

---

#### 2-1. 강사 모집 캠페인 (Phase 1 최우선)

**타겟:** 인스타·유튜브 팔로워 1,000명 이상 레진아트 강사

**메시지 핵심:**
```
[월 수익 비교 메시지]

클래스101 월 매출 300만 원 시 실수령: 약 195만 원 (65%)
오센틱아트 동일 조건:           실수령: 약 260만 원 (86.7%)

차이: 매월 +65만 원 / 연간 +780만 원
```

**채널별 강사 모집 실행 계획:**

| 채널 | 방법 | 주간 목표 | 비고 |
|------|------|---------|------|
| 인스타그램 DM | 레진아트 해시태그 강사 탐색 → 개별 DM | 20건/주 | 대표가 직접 발송 (진정성) |
| 네이버 카페 | 레진아트/공예 강사 커뮤니티 홍보 게시글 | 주 2개 카페 | 광고 아닌 후기 형태 |
| 유튜브 강사 접촉 | 공예 유튜버 DM + 콜라보 제안 | 월 10명 | 협찬 클래스 개설 제안 |
| 오프라인 공방 방문 | 지역 레진아트 공방 직접 방문 설명 | 주 2~3곳 | Phase 1 집중 |

**강사 온보딩 패키지 (첫 3개월 얼리버드):**
- 첫 달 플랫폼 수수료 0% 지원 (강사 100% 수령)
- 강사 소개 페이지 SEO 최적화 무료 지원
- 공식 SNS 강사 피처링 보장 (인스타 1회 + 블로그 1편)

#### 2-2. SEO / 블로그 콘텐츠 전략

**목표 키워드 (Phase 1 집중 공략):**

| 키워드 | 월 검색량 (추정) | 경쟁도 | 우선순위 |
|--------|:---:|:---:|:---:|
| 레진아트 클래스 | 중상 | 중 | P0 |
| 레진아트 원데이클래스 | 중 | 중 | P0 |
| 공예 원데이클래스 [서울/경기/부산…] | 중 | 낮음 | P0 |
| 레진아트 강사되는법 | 중 | 낮음 | P1 |
| 공예 클래스 플랫폼 | 낮음 | 낮음 | P0 |
| 캔들만들기 클래스 | 중 | 중 | P1 |
| 프리저브드플라워 클래스 | 중 | 낮음 | P1 |
| 도자기체험 [지역] | 중 | 낮음 | P2 |

**블로그 100편 제작 계획 (6개월):**

```
월별 생산 목표: 17편 × 6개월

[콘텐츠 필러 5가지]
1. 지역별 클래스 가이드 (40편)
   예: "서울 레진아트 원데이클래스 추천 TOP 5"
       "강남 공예 클래스 모음 2026"

2. 장르 입문 가이드 (20편)
   예: "레진아트 처음 시작하는 법"
       "소이캔들 만들기 재료 준비물 총정리"

3. 강사 인터뷰 · 성공 스토리 (20편)
   예: "월 300만 원 버는 레진아트 강사의 하루"
       "직장 그만두고 공방 열기까지의 여정"

4. 수강생 후기 · 작품 갤러리 (10편)
   예: "레진아트 원데이클래스 후기 · 비기너도 이런 작품 만들었어요"

5. B2B · 팀빌딩 콘텐츠 (10편)
   예: "팀빌딩 아이디어 공예 체험 어때요"
       "기업 문화 행사 공예 프로그램 완벽 가이드"
```

**SEO 온페이지 최적화 (홈페이지 수정):**

```
현재 (레진아트 편향 → 수정 필요):

<title>오센틱아트</title>
→ <title>오센틱아트 — 공예·예술 클래스 예약 & 재료 쇼핑몰</title>

<meta name="description" ...>
→ "레진아트·캔들·플라워·도자기·주얼리 등 전 공예 장르 클래스 예약,
   재료 구매, 작품 거래를 한 곳에서. 강사 수수료 업계 최고 86.7%."

OG 태그, 구조화 데이터(LocalBusiness, Course) 추가
```

#### 2-4. B2B 파이프라인 구축

**타겟:** 50~500인 기업 복지·교육 담당자

**메시지:**
```
"팀원 10명이 함께 만드는 레진아트 코스터
 — 1인당 3만 원, 강사 파견, 재료 일체 포함
 — 2시간 내 완성, 완성품 가져가기
 — 공예 팀빌딩은 오센틱아트로"
```

**영업 채널:**
1. 링크드인 — HR 담당자 DM 영업
2. 기업 복지몰 입점 (퍼플, 복지나라, 베네피아)
3. 지역 상공회의소 기업 복지 행사 제안
4. 인사·복지 담당자 네이버 카페 홍보

**B2B 패키지 구성:**
| 패키지 | 인원 | 단가 | 포함 내용 |
|-------|:---:|:---:|---------|
| 스탠다드 | 10명 | 30만 원 | 레진 코스터 제작 · 재료 · 강사 파견 · 2시간 |
| 프리미엄 | 20명 | 55만 원 | 스탠다드 + 기념 포장 + 단체 사진 |
| 기업 맞춤 | 50명+ | 견적 | 테마 커스텀 · 브랜딩 가능 |

### Phase 2 (6~18개월): 전 장르 확장 + 벤더·에이전시

#### 2-5. 장르 확장 마케팅

**순차 개척 순서:** 레진아트 → 캔들 → 플라워 → 도자기 → 주얼리

각 장르 진입 시 동일한 패턴 반복:

```
[장르 진입 패턴]
1. 해당 장르 Top 5 강사 얼리버드 섭외 (첫 달 수수료 0%)
2. 장르 특화 블로그 20편 발행 (SEO 조기 선점)
3. 인스타 해시태그 장르별 집중 운영 2주
4. 장르 특화 재료 공급사 1~2개 벤더로 입점 유도
5. "XXX장르 클래스 오픈" 공식 보도자료 발행 (무료 채널)
```

#### 2-6. 벤더 파트너 유입 마케팅

**메시지:**
```
"강사가 수강생에게 '이 재료 써보세요'라고 말하는 순간
 판매가 일어납니다. 오센틱아트 벤더로 입점하세요."
```

**유입 채널:**
- 공예 재료 B2B 전시회 참가 (서울 코엑스 한국공예전시회 등)
- 레진아트·공예 재료 공급사 온라인 카페·협회 홍보
- 입점 강사 대상 "지인 공급사 소개 인센티브" 제도 운영

**벤더 입점 인센티브:**
- 첫 3개월 수수료 10% 적용 (이후 15%)
- 강사 연결 우선 노출 보장
- 오센틱아트 공식 SNS 입점 소개 게시물

#### 2-7. 에이전시 파트너 유입 마케팅

**타겟:** 강사 5명 이상 보유 공방·스튜디오·교육 기업

**메시지:**
```
"소속 강사의 정산을 오센틱아트가 직접 처리합니다.
 에이전시는 강사 관리만, 미지급 분쟁은 없습니다."
```

**유입 채널:**
- 공예 교육 협회 네트워크 활용
- 대형 공방 대표 대상 1:1 파트너십 미팅 제안
- 기존 입점 강사 → 소속 에이전시 소개 요청
