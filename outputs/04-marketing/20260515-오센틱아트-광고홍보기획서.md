# 오센틱아트 광고·홍보 기획서
## Phase 1 캠페인 전략 · 소재 · 매체 · 예산 집행 계획

> **캠페인 기간:** 2026년 6월 1일 ~ 8월 31일 (3개월)  
> **핵심 목표:** 강사 50명 모집 · 월 GMV 5,000만 원 달성  
> **총 광고 예산:** 420만 원 (월 140만 원 × 3개월)

---

## 1. 캠페인 전략 개요

### 1-1. 캠페인 구조 (3개 축)

```
캠페인 A — 강사 모집 (공급자 확보)
   타겟: 레진아트·공예 강사
   메시지: "수수료 86.7% — 업계 최고 조건"
   예산 비중: 50%

캠페인 B — 수강생 유입 (수요 창출)
   타겟: 20~40대 공예 관심 여성
   메시지: "내 근처 공예 클래스, 오센틱아트"
   예산 비중: 35%

캠페인 C — B2B 팀빌딩 (고단가 채널)
   타겟: 기업 복지·HR 담당자
   메시지: "팀이 함께 만드는 공예 체험"
   예산 비중: 15%
```

### 1-2. 핵심 메시지 체계

| 타겟 | 핵심 Pain Point | 오센틱아트 해법 | 광고 훅 |
|------|--------------|--------------|--------|
| 강사 | 클래스101·프립 수수료 30~35% | 수수료 13.3%만 공제 → 86.7% 수령 | "클래스 팔면 얼마 남아요?" |
| 수강생 | 클래스·재료·작품 마켓 앱 3개 사용 | 한 앱에서 예약+재료+마켓 | "이걸 왜 여러 앱에서 했지?" |
| 기업 HR | 팀빌딩 아이디어 고갈, 단순 회식 지양 | 강사 파견·재료 일체 포함 공예 체험 | "올해 팀빌딩, 뭔가 다른 걸 해보세요" |

## 2. 광고 소재 기획

### 2-1. 캠페인 A — 강사 모집 소재

---

#### [A-1] 수수료 비교 카드뉴스 (인스타·페북 피드)

**형식:** 정방형(1:1) 5장 슬라이드  
**콘셉트:** 충격적인 숫자 비교 → 공감 → 해법 제시

```
[1장 — 훅]
배경: 짙은 남색 (#1A1A2E)
텍스트(대): "클래스 팔아봤자..."
텍스트(소): "얼마나 남으세요?"

[2장 — 문제 제시]
배경: 흰색
제목: "월 매출 300만 원이면"

표:
플랫폼명    수수료    실수령
클래스101   35%      195만 원
탈잉        20%      240만 원
프립        18%      246만 원
─────────────────────────
오센틱아트  13.3%   260만 원 ★

[3장 — 수치 강조]
배경: 앰버 (#F59E0B) 그라데이션
텍스트(대형): "연간 +780만 원"
텍스트(소): "클래스101 대비 오센틱아트로 옮겼을 때"

[4장 — 신뢰 구축]
배경: 흰색
항목 나열:
✔ 예약·결제·정산 시스템 이미 완성
✔ 강사 스튜디오 + 리뷰 관리
✔ 재료 쇼핑몰 연계 추가 수익
✔ 처음 한 달 수수료 0%

[5장 — CTA]
배경: 남색
텍스트: "지금 강사 신청하기"
링크: authenticart.vercel.app/instructor/apply
```

---

#### [A-2] 릴스 — "강사님, 수수료 얼마 내고 계세요?" (15초)

**콘셉트:** 강사가 직접 말하는 듯한 연출  
**대본:**

```
[0~3초] 훅
화면: 손으로 레진 작품 만드는 클로즈업
자막: "저 원데이클래스 강사인데요..."

[3~8초] 문제
화면: 계산기 두드리는 손
자막: "수강생 5만 원 내면 제 손엔 3만 2천 원?"
       "수수료 35%... 이게 맞아?"

[8~13초] 해법
화면: 오센틱아트 앱 화면 (정산 현황)
자막: "오센틱아트는 13.3%만 가져가요"
       "5만 원 받으면 4만 3천 원 내 것"

[13~15초] CTA
화면: 로고 + URL
자막: "강사 신청 → authenticart.vercel.app"
```

#### [A-3] 네이버·구글 검색광고 텍스트 (강사 타겟)

```
[키워드] 원데이클래스 강사 등록 / 클래스 플랫폼 수수료 / 공예 강사 플랫폼

[광고 제목 1] 강사 수수료 86.7% — 업계 최고
[광고 제목 2] 처음 한 달 수수료 0% 혜택
[광고 제목 3] 레진·캔들·플라워 강사 모집 중

[설명문] 클래스101 대비 연간 780만 원 더 받는 공예 클래스 플랫폼.
예약·결제·정산·재료 쇼핑몰까지 한 번에. 지금 신청하면 첫 달 수수료 0%.
```

### 2-2. 캠페인 B — 수강생 유입 소재

---

#### [B-1] 릴스 — "이 앱 하나면 다 돼요" (20초)

**콘셉트:** Before/After 비교 — 여러 앱 → 오센틱아트 하나

```
[0~5초] 훅
화면: 스마트폰 여러 앱 아이콘 (프립·아이디어스·스마트스토어)
자막: "공예 클래스 예약하려고
       앱 3개 깔았어요 😅"

[5~12초] 문제 공감
화면: 앱 전환하며 헤매는 연출
자막: "클래스는 여기서 예약하고
       재료는 저기서 사고
       작품 팔려면 또 다른 앱..."

[12~18초] 해법
화면: 오센틱아트 앱 화면 자연스럽게 전환
자막: "오센틱아트 하나로 다 해결돼요"
       예약 ✓ 재료구매 ✓ 작품거래 ✓

[18~20초] CTA
자막: "지금 클래스 찾아보기 👇"
```

---

#### [B-2] 지역 타겟 배너 (인스타·페북)

**형식:** 세로형(9:16) 스토리 배너  
**콘셉트:** 지역명 + 장르명 조합으로 개인화

```
[버전 서울]
이미지: 레진아트 작품 클로즈업 (미니멀 배경)
텍스트(대): "서울에서 레진아트 배우기"
텍스트(소): "내 근처 강사가 직접 가르쳐요"
CTA 버튼: "클래스 보기"

[버전 경기]
[버전 부산]
[버전 제주]

→ 지역별 5개 버전 제작, 지역 타겟팅으로 개별 집행
```

#### [B-3] 구글·네이버 검색광고 텍스트 (수강생 타겟)

```
[키워드] 레진아트 원데이클래스 / 공예클래스 근처 / 캔들만들기 클래스

[광고 제목 1] 내 근처 레진아트 클래스 예약
[광고 제목 2] 클래스+재료+작품마켓 한 곳에
[광고 제목 3] 오늘 바로 예약 가능한 공예 클래스

[설명문] 레진·캔들·플라워·도자기 등 전 공예 장르 클래스 예약.
검증된 강사, 리뷰 확인 후 바로 예약. 재료도 같은 앱에서 한번에 구매.
```

## 7. 광고 소재 제작 가이드라인

### 7-1. 비주얼 디렉션

| 항목 | 강사 모집 소재 | 수강생 소재 |
|------|------------|----------|
| 색상 톤 | 남색(#1A1A2E) + 앰버(#F59E0B) — 전문적·신뢰감 | 밝은 파스텔 + 화이트 — 따뜻함·설렘 |
| 이미지 소재 | 작업 중인 강사 손, 작품 완성 순간, 정산 화면 스크린샷 | 수강생 웃는 모습, 완성된 작품 들고 사진, 클래스 분위기 |
| 폰트 | 굵은 산세리프 (숫자 강조 시 임팩트 극대화) | 둥근 계열 고딕 (친근함) |
| 금지 소재 | 스톡 이미지 (어색함), 경쟁사 로고 직접 노출 | 과장된 "대박 수익" 문구 (광고법 위반 리스크) |

### 7-2. 카피 작성 원칙

1. **숫자로 시작** — "86.7%", "연 780만 원", "3만 원"
2. **질문형 훅** — "수수료 얼마 내고 계세요?", "왜 앱을 3개씩 써요?"
3. **Before/After 구조** — 현재 불편함 → 오센틱아트 해법
4. **CTA 명확화** — "지금 신청" / "클래스 찾기" / "견적 요청"
5. **과장 금지** — "최고", "무조건", "보장" 표현 자제 (표시광고법 준수)
