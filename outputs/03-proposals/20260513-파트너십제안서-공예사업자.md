## 1. 우리가 바라보는 시장

### 공예·예술 시장은 지금 급성장 중입니다

| 지표 | 현황 |
|------|------|
| 국내 취미·클래스 시장 규모 | 연 1조 원 이상 (2025년 기준) |
| MZ 세대 핸드메이드·DIY 관심도 | 최근 3년 검색량 **270% 증가** |
| 공예 관련 인스타그램 한국 게시물 | 2억 건 이상 |

**핵심 변화:** 소비자는 더 이상 완성품을 사지 않습니다. **"내가 직접 만든다"**는 경험 자체가 상품입니다.

레진아트로 시작한 수제 공예 트렌드는 이제 캔들, 도자기, 주얼리, 플라워, 목공예, 가죽공예, 자수까지 확산되고 있습니다. 그런데 이 시장을 **하나의 플랫폼**으로 묶어주는 곳이 아직 없습니다.

오센틱아트는 그 공백을 채웁니다.

## 2. 오센틱아트가 걷고 있는 길

### "레진아트 플랫폼"에서 "공예·예술 종합 플랫폼"으로

```
현재 (2025)                        목표 (2027)
──────────────────────────────────────────────────
레진아트 중심 클래스 플랫폼    →  전 공예 장르 아우르는 예술 생태계
강사 개인 단위 운영            →  브랜드·공급사·스튜디오 파트너 체계
국내 클래스 예약               →  온·오프라인 통합 + 작품 마켓
```

**이미 구축된 인프라:**

- 강사 스튜디오 시스템 (클래스 등록, 일정 관리, 정산)
- 수강생 예약·결제·후기 시스템
- 작품 마켓 (수강생 작품 거래)
- 재료 쇼핑몰 (공예 재료 판매)
- 단체 출강 요청 시스템
- 지부 네트워크 (전국 확장 구조)

**귀사가 합류하면 이 인프라 전체가 귀사의 것이 됩니다.**

## 3. 파트너십 모델 — 어떻게 함께할 수 있나요?

### 모델 A | 공식 재료 공급 파트너

> **대상:** 공예 재료 도매·소매 사업자, 브랜드

**구조:**
- 플랫폼 내 공식 재료몰 입점
- 강사가 클래스 준비물 안내 시 귀사 제품 자동 연결
- 수강생이 클래스 예약 후 재료 구매까지 원스톱 처리

**수익 구조:**
```
수강생이 클래스 예약
    ↓
"준비물 구매" 버튼 노출 (귀사 상품 링크)
    ↓
귀사 매출 발생 + 플랫폼 수수료 협의
```

**기대 효과:**
- 클래스 연계 재구매 — 수강생은 클래스 후 반드시 재료를 더 삽니다
- 강사 추천 신뢰도 — 전문 강사의 "쓰는 재료" 추천 효과
- 재고 판매 채널 다각화

---

### 모델 B | 클래스 콘텐츠 파트너

> **대상:** 공예 브랜드, 스튜디오, 학원, 기업

**구조:**
- 귀사 브랜드명으로 공식 클래스 채널 개설
- 소속 강사 또는 브랜드 강사의 클래스 집중 노출
- 브랜드 스토리·철학을 클래스로 전달하는 콘텐츠 마케팅

**예시:**
```
[캔들 브랜드 A] 공식 클래스
  ├─ "A 시그니처 캔들 제작" — 브랜드 레시피 공개
  ├─ "선물용 캔들 래핑 원데이" — 구매 전환 유도
  └─ "캔들 메이커 양성 과정" — 강사 양성 수익화
```

**수익 구조:**
- 클래스 수익의 86.7% 강사(브랜드) 수령
- 플랫폼 수수료 10% + PG 수수료 3.3%만 공제
- 재료 패키지 동시 판매 시 추가 수익

---

### 모델 C | 작품 유통 파트너

> **대상:** 공예 작가, 소규모 공방, 핸드메이드 브랜드

**구조:**
- 오센틱아트 마켓에 작품·상품 등록
- 수강생 커뮤니티 → 진성 고객층에 직접 노출
- 클래스 수강 후 작가 작품 구매로 이어지는 자연스러운 퍼널

**기대 효과:**
- "수업 들은 작가 작품 사고 싶어요" 수요를 직접 흡수
- SNS 마케팅 없이도 플랫폼 내 유입 고객 확보
- 작품 스토리 + 클래스 연결로 프리미엄 가격 형성 가능

---

### 모델 D | 기업 단체 출강 파트너

> **대상:** 기업 복지·교육 담당자, 이벤트 기획사

**구조:**
- 기업 팀빌딩, 문화행사, 신입 교육용 단체 클래스 공급
- 귀사가 보유한 강사/콘텐츠를 플랫폼 B2B 채널을 통해 기업에 판매
- 1회 계약 → 반복 수주로 이어지는 B2B 파이프라인

**시장 규모:**
> 국내 기업 복지 예산 중 "체험형 문화 활동" 비중은 연 8,000억 원 이상 (2024 HR 트렌드 리포트)

---

### 모델 E | 지부 네트워크 파트너 (공동 사업)

> **대상:** 지역 공방, 스튜디오, 공예 센터

**구조:**
- 오센틱아트 공식 지부로 운영
- 귀사 공간 + 강사 → 플랫폼 예약·결제·정산 시스템 활용
- 오센틱아트 브랜드 신뢰도 + 귀사 로컬 네트워크 결합

```
귀사가 가진 것:  공간 + 지역 강사 + 수강생 네트워크
오센틱아트가 제공: 예약 시스템 + 결제 + 정산 + 마케팅 + 브랜딩
         ↓
함께 만드는 것:  지역 대표 공예·예술 허브
```

**지부 파트너 혜택:**
- 플랫폼 내 "공식 지부" 배지 및 우선 노출
- 전국 수강생 유입 (타 지역 방문객 포함)
- 단체 출강 요청 우선 배정
- 재료 도매가 공급 연결

## 4. 왜 지금 합류해야 하는가?

### 선점 효과가 결정합니다

플랫폼이 성장할수록 파트너 자리는 좁아집니다.

```
지금 합류하면                   나중에 합류하면
─────────────────────────────────────────────
공식 파트너 브랜딩 획득         경쟁사와 동일 조건
낮은 수수료율 협의 가능          표준 약관 적용
플랫폼 성장과 함께 자산 형성    이미 형성된 파이 나누기
제품·콘텐츠 카테고리 선점       후발 진입자로 시작
```

### 오센틱아트가 가진 것 — 귀사가 직접 구축하려면?

| 항목 | 직접 구축 시 | 오센틱아트 파트너 |
|------|------------|----------------|
| 예약·결제 시스템 | 최소 5,000만 원 + 1년 | **즉시 사용** |
| PG사 계약 | 2~3개월 심사 | **처리됨** |
| 강사 모집 채널 | 별도 운영 필요 | **플랫폼 내 강사풀** |
| 수강생 유입 | 광고비 월 수백만 원 | **플랫폼 트래픽 공유** |
| 정산 자동화 | 개발 필요 | **자동 정산 시스템** |
| 브랜드 신뢰도 | 0에서 시작 | **기존 수강생 리뷰·후기** |

## 7. 자주 묻는 질문

**Q. 현재 자사몰이나 클래스 채널을 운영 중입니다. 중복 우려가 없나요?**
A. 오센틱아트는 기존 채널을 대체하는 것이 아니라 새로운 고객 유입 채널을 추가하는 개념입니다. 귀사 기존 채널과 병행 운영을 권장합니다.

**Q. 최소 물량이나 계약 금액이 있나요?**
A. 파트너 모델에 따라 다릅니다. 소규모 작가도 부담 없이 시작할 수 있는 구조입니다. 상세 조건은 미팅에서 협의합니다.

**Q. 정산은 어떻게 이루어지나요?**
A. 매월 1일 마감 기준, 5일에 등록 계좌로 자동 입금됩니다. 실시간 수익 현황은 파트너 대시보드에서 확인 가능합니다.

**Q. 플랫폼이 성장하지 않으면 리스크가 있지 않나요?**
A. 귀사가 부담해야 할 초기 비용이 없는 구조(시스템 사용료 없음, 매출 발생 시에만 수수료)이므로 리스크는 최소화됩니다.
