## PART 2. 첨부용 강사 모집 제안서 본문

# 강사님, 지금 수수료 얼마 내고 계신가요?

## 오센틱아트가 드리는 제안

> **강사님이 받아야 할 몫을 드립니다.**
> 가르치는 것에만 집중하세요. 나머지는 오센틱아트가 다 합니다.

---

## 1. 먼저, 현실을 직시해봅시다

지금 강사님의 하루를 생각해보세요.

**클래스 전에 해야 하는 일들**
```
카카오 오픈채팅 모집 공고 올리기
DM 문의 일일이 답변하기
입금 확인, 미입금자 독촉하기
인원 확정 후 날짜 재조율하기
재료 준비 목록 보내주기
장소 안내 반복 발송하기
```

**클래스 당일**
```
노쇼 연락 대기하기
환불 문의 처리하기
현금 영수증 요청 처리하기
```

**클래스 후에 해야 하는 일들**
```
후기 독촉 메시지 보내기
재예약 문의 응대하기
정산 날짜 기다리기 (늦으면 직접 문의)
다음 달 모집 공고 또 올리기
```

**그리고 이 모든 일을 하면서 — 수수료 35%를 냅니다.**

강사님이 가르치는 게 직업인지, 행정 업무가 직업인지 모를 지경이죠.

---

## 2. 수수료 비교 — 숫자로 확인하세요

### 강사 실수령율 비교

| 플랫폼 | 강사 수수료 | 플랫폼이 가져가는 비율 |
|-------|-----------|-------------------|
| **오센틱아트** | **86.7%** | **13.3%** (PG 3.3% + 플랫폼 10%) |
| 탈잉 | 80% | 20% |
| 프립 | 75% | 25% |
| 클래스101 | 65% | 35% |
| 크몽 | 70~80% | 20~30% |

> **오센틱아트 13.3% 구성:**
> - PG 수수료 3.3% → 카드사에 내는 비용 (저희도 어쩔 수 없음)
> - 플랫폼 수수료 10% → 예약·결제·정산·마케팅·서버 비용 전부 포함
> - 추가 비용: 없음

---

### 월 매출별 연간 수입 차이

| 월 클래스 매출 | 클래스101 (65%) | **오센틱아트 (86.7%)** | 연간 차이 |
|-------------|--------------|---------------------|---------|
| 100만 원 | 65만 원 | **86.7만 원** | **+260만 원** |
| 200만 원 | 130만 원 | **173.4만 원** | **+520만 원** |
| 300만 원 | 195만 원 | **260.1만 원** | **+780만 원** |
| 500만 원 | 325만 원 | **433.5만 원** | **+1,300만 원** |

**같은 클래스, 같은 노력으로 — 연간 500만~1,300만 원이 달라집니다.**

이 돈으로 재료를 더 사고, 장비를 업그레이드하고, 여행을 가고, 저축을 할 수 있습니다.

---

## 3. 오센틱아트에서 강사님이 얻는 것

### 강사님의 시간을 돌려드립니다

| 지금 강사님이 직접 하는 일 | 오센틱아트에서는 |
|------------------------|--------------|
| 카카오 문의 일일이 답변 | 수강생이 직접 예약·결제 완료 |
| 입금 확인·독촉 | 결제 완료 즉시 자동 확정 |
| 노쇼 대응·환불 처리 | 취소 정책 자동 적용 |
| 정산 날짜 기다리기 | 매월 5일 자동 이체 |
| 다음 달 모집 공고 반복 | 클래스 상시 노출, 상시 예약 |
| 후기 수동 관리 | 수강 후 자동 후기 요청 |

**하루 평균 1~2시간씩 행정 업무에 쓰던 시간 = 한 달 30~60시간**
이 시간을 연구, 클래스 준비, 개인 작업, 휴식에 쓸 수 있습니다.

---

### 강사 전용 스튜디오 페이지 — 무료 제공

오센틱아트에 가입하면 강사님만의 **스튜디오 페이지**가 생깁니다.

```
[강사님 스튜디오]
──────────────────────────────────
프로필 사진  |  강사 소개 스토리
──────────────────────────────────
개설 클래스 목록         예약하기 버튼
클래스 사진·설명·일정   바로 결제
수강생 후기 (별점)       남은 자리 표시
──────────────────────────────────
누적 수강생 N명   후기 N개   별점 ★4.9
```

이 페이지 링크 하나로 **인스타그램 바이오 링크, 카카오 프로필 링크**로 활용하세요.
별도 링크 페이지 서비스 구독료 아낄 수 있습니다.

---

### B2B 기업 출강 — 예상치 못한 추가 수입

오센틱아트에는 기업 팀빌딩 수요가 플랫폼으로 직접 들어옵니다.

> 기업 복지 담당자: "20명 팀빌딩 공예 체험 강사 연결해주세요"
> → 오센틱아트가 해당 장르·지역 강사에게 자동 매칭

**기업 출강 단가 (예시):**

| 인원 | 시간 | 강사 수령 (예시) |
|------|------|--------------|
| 10인 | 2시간 | 15~20만 원 |
| 20인 | 2시간 | 30~40만 원 |
| 50인 | 2.5시간 | 70~90만 원 |

정규 클래스 외에 월 1~2건만 출강해도 **월 30~80만 원 추가**입니다.
이런 기업 요청을 강사 혼자 직접 받기는 쉽지 않습니다.

---

### 재료 추천 수익 — 수강생이 재료 살 때마다

클래스 준비물 안내 시 오센틱아트 재료몰 상품을 연결하면,
수강생이 구매할 때마다 **추가 수익**이 발생합니다.

"이번 클래스에 필요한 재료는 여기서 구매하세요" — 클릭 한 번.
강사님이 신뢰하고 쓰는 재료를 수강생이 동일하게 씁니다.

---

## 4. 강사님이 걱정할 수 있는 것들 — 미리 답변드립니다

**"지금 쓰는 플랫폼 끊어야 하나요?"**
아닙니다. 오센틱아트는 추가 채널로 운영하시면 됩니다.
기존 채널 유지하면서 오센틱아트도 병행하셔도 됩니다.
독점 계약 조항 없습니다.

**"수강생이 오센틱아트에 있나요? 새로 모아야 하나요?"**
강사님의 기존 수강생을 오센틱아트로 불러오시면 됩니다.
"앞으로 예약은 여기서 해주세요" 한 마디면 됩니다.
동시에 플랫폼 내 신규 수강생도 유입됩니다.

**"플랫폼이 망하면 수강생 데이터 잃는 거 아닌가요?"**
강사님의 수강생은 강사님 것입니다.
수강생 연락처, 예약 이력은 언제든 내보내기 가능합니다.

**"클래스 최소 개수나 의무가 있나요?"**
없습니다. 월 1개 클래스도 됩니다. 일시정지도 됩니다.
강사님이 원할 때 원하는 만큼만 운영하세요.

**"가입비나 월정액이 있나요?"**
없습니다. 클래스 수익이 발생할 때만 13.3%가 차감됩니다.
수익 0원이면 수수료도 0원입니다.

## 5. 지금 합류해야 하는 이유 — 타이밍이 전부입니다

플랫폼은 선점이 전부입니다.

지금 오센틱아트에 강사 50명이 있을 때와
1,000명이 됐을 때 — 강사님의 노출 위치는 완전히 다릅니다.

**얼리 파트너 강사에게 드리는 혜택:**

| 혜택 | 내용 |
|------|------|
| 플랫폼 메인 추천 강사 등록 | 신규 수강생에게 우선 노출 |
| 오센틱아트 SNS 강사 소개 | 인스타·카카오 공식 계정 홍보 |
| B2B 출강 우선 배정 | 기업 요청 시 얼리 파트너 먼저 매칭 |
| 기능 개발 우선 반영 | 필요한 기능 직접 요청 가능 |

**이 혜택은 초기 강사 50명에게만 적용됩니다.**
