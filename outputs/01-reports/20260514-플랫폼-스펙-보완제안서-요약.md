## GAP별 핵심 내용

### GAP 1. 카테고리 체계 재설계 (P0)

**문제:** 클래스·상품·작품 카테고리가 각각 다르게 정의되어 있어 장르 필터 불가능.

**해결:** 통합 2계층 카테고리 테이블(`craft_categories`) 신설 — **8개 대카테고리 전체 동시 오픈 ✅**

| 대카테고리 (8개) | 소카테고리 예시 |
|:---:|:---:|
| 레진아트 | 코스터·트레이 / 주얼리 / UV레진 / 에폭시아트 |
| 캔들·디퓨저 | 소이캔들 / 밀랍캔들 / 젤캔들 / 디퓨저 |
| 플라워·압화 | 프리저브드 / 드라이 / 압화액자 / 생화 |
| 도자기·석고 | 물레도자기 / 핀칭 / 석고방향제 |
| 주얼리·비즈 | 와이어 / 비즈목걸이 / 실버 / 천연석 |
| 자수·뜨개·패브릭 | 프랑스자수 / 코바늘 / 대바늘 / 스트링아트 |
| 회화·수채화 | 수채화 / 아크릴화 / 유화 / 캘리그라피 |
| 목공예·가죽·기타 | 목공예 / 가죽공예 / 마크라메 / 종이공예 |

- 클래스·상품·작품·강사 프로필 모두 동일 카테고리 FK 사용

### GAP 2. 상품 입점사(멀티벤더) 시스템 (P0)

**문제:** 외부 공급사가 상품을 직접 등록·판매할 수 없음 (관리자 직영 구조).

**해결:** `vendors` 테이블 + `vendor_payouts` 정산 자동화

**수수료 구조 (위탁 판매):**
```
판매가 100%  →  플랫폼 수수료 15%  +  벤더 정산 85%
```

**주요 추가 기능:**
- 벤더 신청 → 어드민 승인 → 상품 등록 → 월 자동 정산
- **클래스-재료 연결:** 강사가 클래스에 준비물 상품 연결 → 예약 후 "준비물 구매" 원스톱

**필요 화면:** 벤더 신청 / 벤더 대시보드 / 어드민 벤더 관리·정산

---

### GAP 3. 강사 에이전시 시스템 (P1)

**문제:** 공방·스튜디오·에이전시가 소속 강사를 묶어서 입점할 방법 없음.

**해결:** `agencies` 테이블 + 에이전시별 수수료율 개별 설정 / 플랫폼이 강사·에이전시 양쪽 직접 정산

| 에이전시 수수료율 | 강사 수령 | 에이전시 수령 | 플랫폼 | PG |
|:---:|:---:|:---:|:---:|:---:|
| 0% (개인 동일) | **86.7%** | — | 10% | 3.3% |
| 5% | **81.7%** | 5% | 10% | 3.3% |
| 10% | **76.7%** | 10% | 10% | 3.3% |
| 15% | **71.7%** | 15% | 10% | 3.3% |

> 어드민이 에이전시별로 수수료율 직접 설정. 플랫폼 직접 분리 지급으로 강사 미지급 분쟁 차단.

**필요 화면:** 에이전시 신청 / 소속 강사 관리(초대 링크) / 에이전시 대시보드 / 어드민 에이전시 관리

### GAP 4. 지부 수수료 로직 (P1)

**문제:** `branches.commission_rate` 필드는 있지만 예약 정산에 반영 안 됨.

**해결:** 예약 생성 시 지부 커미션 자동 계산 + `branch_payouts` 정산 테이블 추가

```
플랫폼 수수료 10만 원  →  지부 배분 30% = 3만 원  /  본사 7만 원
```

### GAP 5. 홈페이지 브랜드 전환 (P1)

**문제:** 레진아트 편향 이미지, Trust Bar 문구, SEO 메타 태그.

**해결 포인트:**
- 장르 탐색 섹션 추가: `[레진아트] [캔들] [플라워] [도자기] [주얼리] [자수] [회화] [목공예]`
- SEO 메타: "공예·예술 클래스 & 재료 쇼핑 플랫폼"으로 교체
- UGC 갤러리 이미지: 각 장르 균등 배분

### GAP 6. 클래스 장르 필터 (P2)

**문제:** 클래스 목록에 지역 탭만 있고 장르 필터 없음.

**해결:** GAP 1 카테고리 시스템 구현 후 상단 수평 탭으로 연동 ✅

```
[전체] [레진아트] [캔들] [플라워] [도자기] [주얼리] [자수] [회화] [목공예]
                       + [지역 ▼] [난이도 ▼] [가격 ▼]
```

### GAP 7. 작품 마켓 수수료 (P2)

**문제:** 작품 판매 수익이 판매자(수강생) 100% 귀속, 플랫폼 수익 없음.

**해결:** 판매자 개인 월 거래량 기반 구간별 수수료 ✅

| 조건 | 수수료 | 판매자 수령 |
|------|:---:|:---:|
| 개인 월 거래 100건 미만 (기본) | 10% | 90% |
| 개인 월 거래 100건 이상 | 8% | 92% |
| 개인 월 거래 200건 이상 | 5% | 95% |
| 단가 50만 원 이상 (건별 즉시) | 5% | 95% |

**리셋 기준 — 매월 1일 초기화 + 하락 시 1개월 유예:**

| 케이스 | 전월 거래 | 전월 수수료 | 이번 달 적용 |
|--------|:---:|:---:|:---:|
| 상승 (수수료 인하) | 120건 | 10% | **8% 즉시** |
| 상승 (수수료 인하) | 230건 | 8% | **5% 즉시** |
| 하락 (수수료 인상) | 80건 | 5% | **5% 유예** |
| 유예 종료 | 80건 연속 | 5%→유예 | **10% 적용** |

> 경쟁사 아이디어스 20% 대비 최대 절반 이하. 많이 팔수록 수수료가 낮아지는 성장 인센티브.  
> DB: `seller_artwork_stats` (판매자별 월 거래량·적용 수수료율·유예 여부 관리)

### GAP 8. 소비자 보호 장치 (P1)

**문제:** 결제~정산 사이 보호 장치 전무. 벤더 오픈 즉시 전자상거래법 적용 대상.

**거래 유형별 보호 설계:**

| 거래 유형 | 핵심 보호 장치 |
|---------|-------------|
| **클래스 예약** | 취소 정책 표준화 (D-3↑ 100% / D-1~2 50% / 당일 0%) + 강사 귀책 취소 3회 패널티 |
| **재료 쇼핑몰** | 전자상거래법 청약철회 7일 + 배송완료 후 7일 자동 구매확정 + DeliveryTracker 배송 추적 |
| **작품 마켓** | P2P 에스크로 홀드 + 배송완료 후 3일 자동 구매확정 |
| **공통** | 분쟁 신고 창구(`disputes` 테이블) + 어드민 처리 화면 `/admin/disputes` |

> **배송 추적 API:** DeliveryTracker (delivery-tracker.net) — CJ·한진·롯데·우체국 등 국내 전 택배사 통합 지원 ✅
