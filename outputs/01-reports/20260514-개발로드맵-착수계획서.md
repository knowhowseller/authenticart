## 1. 프로젝트 개요

### 목적

현재 "레진아트 중심 클래스 플랫폼"을 비즈니스 보고서 목표인 **"공예·예술 종합 플랫폼"** 으로 전환하기 위한 핵심 인프라를 구축한다.

### 핵심 목표 4가지

| # | 목표 | 관련 GAP | 완료 기준 |
|---|------|---------|---------|
| 1 | 전 장르 공예·예술 카테고리 통합 체계 | GAP 1·5·6 | 8개 장르 필터로 클래스 탐색 가능 |
| 2 | 멀티벤더·에이전시 파트너 입점 구조 | GAP 2·3 | 외부 공급사·에이전시 신청→승인→정산 완성 |
| 3 | 작품 마켓 수익화 및 지부 수수료 자동화 | GAP 4·7 | 거래량·단가 연동 수수료 자동 계산 |
| 4 | 거래 유형별 소비자 보호 체계 | GAP 8 | 에스크로·취소정책·분쟁창구 운영 가능 |

```typescript
const PG_RATE       = 0.033
const PLATFORM_RATE = 0.10

export function calcBookingFees(gross: number, agencyRate: number = 0) {
  const pgFee            = Math.round(gross * PG_RATE)
  const platformFee      = Math.round(gross * PLATFORM_RATE)
  const agencyFee        = Math.round(gross * agencyRate / 100)
  const instructorPayout = gross - pgFee - platformFee - agencyFee
  return { pgFee, platformFee, agencyFee, instructorPayout }
}
```

**기준: 판매자 개인 월 거래량 / 매월 1일 초기화 / 하락 시 1개월 유예**

```typescript
// lib/utils/fees.ts

function rateFromCount(count: number): number {
  if (count >= 200) return 5
  if (count >= 100) return 8
  return 10
}

// 주문 생성 시 — seller_artwork_stats.applied_rate 조회 후 계산
export async function calcArtworkFee(price: number, sellerId: string) {
  if (price >= 500_000) {
    // 단가 50만 원↑: 거래량 무관, 즉시 5%
    const platformFee = Math.round(price * 5 / 100)
    return { platformFee, sellerPayout: price - platformFee, rate: 5, reason: 'high_value' }
  }
  const stats = await getSellerArtworkStats(sellerId)
  const rate  = stats?.applied_rate ?? 10   // 이력 없으면 기본 10%
  const platformFee  = Math.round(price * rate / 100)
  return { platformFee, sellerPayout: price - platformFee, rate, reason: 'seller_tier' }
}
```

| 케이스 | 전월 거래 | 전월 수수료 | 이번 달 적용 | 비고 |
|--------|:-------:|:--------:|:----------:|------|
| 상승 (인하) | 120건 | 10% | **8%** | 즉시 적용 |
| 상승 (인하) | 230건 | 8% | **5%** | 즉시 적용 |
| 하락 (인상) | 80건 | 5% | **5%** | 유예 1개월 |
| 하락 유예 종료 | 80건 | 5% (유예) | **10%** | 유예 종료 |

#### Phase 3 완료 기준

```
✅ 지부 소속 강사 예약 시 branch_commission 자동 계산
✅ 작품 판매 시 판매자 개인 이번 달 applied_rate 기반 수수료 자동 계산
✅ 월초 Cron 실행 후 전월 거래량 기반으로 수수료율 갱신 (하락 시 유예 적용 확인)
✅ 수강생이 클래스 취소 시 D-day 기준 환불율 자동 계산
✅ 강사 귀책 취소 3회 시 관리자 알림 발송
✅ 운송장 번호 입력 후 배송 현황 실시간 조회 가능 (DeliveryTracker)
✅ 재료 주문 배송완료 후 7일 뒤 자동 구매확정 동작
✅ 작품 주문 배송완료 후 3일 뒤 자동 구매확정 동작
✅ 분쟁 신고 후 어드민 처리 → 정산 홀드·환불 실행 가능
```

#### DeliveryTracker API 연동 상세

**선택 API:** DeliveryTracker (delivery-tracker.net)  
**이유:** 국내 전 택배사(CJ대한통운·한진·롯데·우체국·로젝트·CU 등 20개↑) 단일 API로 통합 조회 가능, 무료 플랜으로 시작 가능

**지원 택배사 코드 예시:**

| 택배사 | 코드 |
|--------|------|
| CJ대한통운 | `kr.cjlogistics` |
| 한진택배 | `kr.hanjin` |
| 롯데택배 | `kr.lotte` |
| 우체국택배 | `kr.epost` |
| 로젝트(구 로엔) | `kr.logen` |
| CU 편의점택배 | `kr.cupost` |

**API 호출 구조:**

```typescript
// lib/delivery/tracker.ts

const TRACKER_API = 'https://apis.tracker.delivery/carriers'

export async function getTrackingInfo(carrierCode: string, trackingNo: string) {
  const res = await fetch(
    `${TRACKER_API}/${carrierCode}/tracks/${trackingNo}`,
    { headers: { 'Authorization': `Bearer ${process.env.DELIVERY_TRACKER_API_KEY}` } }
  )
  if (!res.ok) throw new Error('배송 조회 실패')
  return res.json()  // { state: { id, text }, progresses: [...] }
}

// 배송 상태 코드
// 'at_pickup'     → 픽업 완료
// 'in_transit'    → 배송 중
// 'out_for_delivery' → 배달 출발
// 'delivered'     → 배달 완료  ← 이 상태 도달 시 자동확정 타이머 시작
```

**자동확정 Cron 흐름:**

```
[Cron: 1시간마다 실행]
  ↓
delivery_status = 'in_transit' 인 주문 조회
  ↓
DeliveryTracker API 호출
  ↓
state = 'delivered' 이면
  → orders.delivery_status = 'delivered'
  → orders.auto_confirm_at = NOW() + 7일  (재료 주문)
  → artwork_orders.auto_confirm_at = NOW() + 3일  (작품 주문)

[Cron: 1일 1회 실행]
  ↓
auto_confirm_at <= NOW() 이고 dispute_status = 'none' 인 주문
  → confirmed_at = NOW()
  → payout_status = 'pending'  (정산 대기 전환)
```

**필요 환경변수:**

```
DELIVERY_TRACKER_API_KEY=   # DeliveryTracker 발급 API 키
```
